# V2.4 — Ocean Interaction

> Part of the SILENT DEPTH V2.4 → V3.0 visual roadmap. Focus: the #1 V2.2.5 QA
> problem — *the sea had no real interaction with the player or the fleet*.

## What changed (presentation-only)

- New `src/renderer/three/wake/WakeSystem.ts`
  - Pure, RenderState-only wake source collector. Reads `position / heading / speed /
    visible` only. **Never** writes to simulation, AI, sonar or physics.
  - `collectWakeSources(state)` always emits the player submarine wake, and emits a
    wake for **each already-visible enemy ship** (visibility is decided upstream by
    the adapter from sonar / periscope detection). Stopped vessels produce no wake.
  - `wakeFoamIntensity(px, pz, src)` is a pure mirror of the GLSL `shipWake` so JS
    unit tests and the GPU agree on wake shape.
  - Wake components: **bow wave**, **stern turbulent foam**, **Kelvin V-wake**
    (~19° diverging lines), and a transverse breakup so the trail is not a clean
    stripe. Width scales per class (submarine slim → tanker broad).
  - `MAX_WAKES = 12` hard cap; ships beyond the cap are silently dropped (no
    gameplay effect).
- `OceanRenderer.ts` rewritten:
  - Consumes the wake array via uniform arrays (`uWakePos / uWakeHeading /
    uWakeSpeed / uWakeWidth / uWakeCount`).
  - **Four spatial layers** of the sea:
    - *Near* — high-frequency ripple, strongest close to the camera.
    - *Mid* — the default mixed swell.
    - *Far* — broad low-frequency swell that grows with distance.
    - *Horizon* — a separate `farMesh` (600×600, low-frequency) that dissolves
      into the fog colour so the sea meets the sky believably.
  - **Storm foam bands**: wind-aligned streaks plus existing crest foam.
  - **Dark troughs**: wave valleys read darker, raising storm contrast.
  - Legacy single-player-wake path retained as a fallback if no WakeSystem is
    supplied (renderer stays alive even if wiring is incomplete).
