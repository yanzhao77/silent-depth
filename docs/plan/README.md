# UE4 独立游戏开发规划

整理日期：2026-09-14；设计版本：0.2。

SILENT DEPTH 的唯一开发产品是 UE4.27 独立游戏，目标在 Steam 发售。
本目录集中保存 16 份规划分册，包括 100 个场景用例与 8 组高风险组合。
它们是待批准、待实现和待验证的设计资料，不是已经冻结的最终规格或已运行测试。

## 最近审查待修项

以下问题来自 2026-09-14 的文档审查。本次仅整理目录，保留规划正文，未修正这些规则。

| 优先级 | 问题 | 涉及分册 |
|---|---|---|
| P1 | 来袭鱼雷如何分类、估距并触发规避，尚未形成完整感知规则 | 03、13 |
| P1 | 光学观测缺少目标自身浮出水面等可见条件，不能只检查观察者、视角与距离 | 03、13 |
| P1 | 两次带误差测距直接推导速度可能拒绝正常目标，需明确抗误差估计规则 | 03、13 |
| P2 | 研究能力与武器配置尚缺正式节点、合法装备/装位及本地资产映射 | 13、15 |
| P2 | 现有档案到新路线、经济与 A/B 槽的具体版本迁移表尚未落定 | 05、14 |

火控纸面反例：4 km 的静止目标，两次合法测距可为 3.68 km 与 4.32 km；
间隔 20 秒直接差分会得到约 62.2 kt 的虚假速度。该算例不是 UE 实机结果。
修正上述规则前，不把 0.2 版描述为无歧义的最终实施规范。

## 状态与边界

已确认的是 UE4 唯一主线与 Steam 目标；具体首发范围、参数与平台候选功能仍需批准。
代码、配置和新执行检查说明当前事实；本目录说明目标，不因文字写全而获得完成标签。
新规则的参数落入正式配置后，文档引用配置键，不维护第二套数值真值。

现有基线仍记录运行时同步漂移和 45 项资产验证文件哈希错误；本次整理没有修复它们。
UBT、UE Automation、视觉、目标硬件和 Steam 发行结果仍须按实际执行记录，不借用文档检查。
UI 视觉稿、正式资产选型、许可审核与发布包验证是后续交付，不是本目录中的已完成资产。
