# 界面与交互规格

版本：0.2；日期：2026-09-14；性质：界面流程、控件、输入与视觉规格提案。
不是 UMG 实现、最终美术稿或编辑器验收；全部布局效果为 `NOT VERIFIED`。

## 1. 全局原则

- 优先级：世界场景 > 当前玩法决策 > HUD > 元数据。
- 港口回答“我用什么艇去做什么”；战斗回答“知道什么、能做什么、风险是什么”。
- 每个页面有一个主要动作和明确返回位置，不把所有系统变成首页弹窗。
- 全部游戏界面使用 UE4 UMG/Slate；不引入网页界面、浏览器组件或另一套运行时前端。
- 显示与操作只用既有或正式扩展的只读模型和指令服务；不维护影子账户、隐藏敌表或独立任务状态。

## 2. 页面流程

```text
启动与存档检查
  -> 首次设置 -> 教学选择 -> 教学任务 -> 港口
  -> 已有档案 -> 港口 / 继续已保存任务

港口 -> 行动选择 -> 简报 -> 配装检查 -> 装载 -> 战斗
港口 -> 舰艇研发 -> 节点详情 -> 研究确认 -> 返回原位置
港口 -> 配装 -> 候选预览 -> 保存 -> 港口
战斗 -> 暂停 -> 继续 / 保存退出 / 中止确认
战斗 -> 唯一结果 -> 结算保存 -> 战报 -> 港口 / 再次出航
```

设置为独立覆盖页，返回时保留原页面选择、滚动和焦点；退出动作不得绕过未保存状态处理。

## 3. 港口文字线框

```text
顶部：SILENT DEPTH | 港口 | 行动 | 研发                 研究点 | 设置
左侧：当前艇名称、角色、已应用配装摘要
中央：不加装饰边框的可旋转潜艇场景
右侧：选中行动的目标与约束摘要                         出航
底部：已拥有舰艇列表、筛选与当前选择
```

默认展示当前拥有艇；没有合法拥有艇时显示明确空态，不偷偷选择资产表回退艇作为所有权。
中央模型可观察外形与装备，不播放长时间不可跳过的入港动画。
潜艇展厅可作为独立资料功能后续评估，不进入首个切片必需范围。

## 4. 行动与简报

左侧任务列表，中央离线海域图，右侧选中任务简报；不显示实时隐藏敌军。
简报字段：主要目标、撤离要求、已知情报与不确定性、环境、必要能力、奖励规则。
返回港口保留选择；配置不满足时提供定位到相关装位的入口，不允许直接出航。
装载页提供真实加载状态与可解释失败；禁止用固定延迟假装资源正在加载。

## 5. 科技树与配装

科技树以舰艇研发为主；分类和筛选用页签或菜单，不用长段落按钮充当所有交互。
节点详情显示成本、用途、合法依赖、资料性质和已批准的能力差异。
只显示模型授权公开的研发元数据；未解锁装备不得混入可用配装候选，缺模型数据则失败关闭。
“资料不足”“无外观”“未通过资产验收”“不能装备”是不同状态，不能合成一个灰色锁图标。

配装围绕当前艇，选择一个系统后显示装位与候选；选中候选才显示对比。
预览不改档案，确认才执行服务事务；保存失败保留旧配置并显示错误。
研究后留在原节点，可直接进入该艇合法配装，不把玩家送回树的起点。

## 6. 战斗文字线框

```text
顶部中：航向刻度                         顶部角落：任务阶段、暂停
中央：世界视图 / 战术图 / 潜望镜，只保留当前视图
左下：航速、深度、船体、静默与本艇噪声
右侧：选中接触、观测时间、估计质量、当前火控
底部：鱼雷管与弹药、主动声呐、诱饵、必要系统操作
短事件区：新接触、声呐入射、已感知武器、近爆等有限报告
```

世界视图表现本艇和依法可见实体；不将声呐接触直接变成实体轮廓。
战术图强调方位线、估计区间、航迹和任务区域；不以中心点替代整个不确定区域。
潜望镜只显示当前合法光学视野与授权观测；不能利用镜头位置扩大玩法视距。
核潜艇不显示无玩法含义的电池条。未被公开的敌方警戒或跟踪状态不显示精确数值。

重要动作使用符号加必要文字，危险动作明确命名。没有数据不显示伪精度或填零冒充测量值。
事件区有数量和时间上限；完整记录通过暂停后的日志入口阅读，不持续遮挡目标。

## 7. 战报与继续

首先给出成功、失败或中止，以及权威结果原因；随后是目标结果、关键事件、研究收益。
保存完成前显示待提交状态，不先播放“研究点到账”动画。
失败时提供重试与返港；重试创建新任务实例，不能再次消费旧结果。
首个版本的复盘不展示全知敌舰轨迹，参见 [游戏设计](02_GAME_DESIGN.md)。

## 8. 必需交互状态表

| 场景 | 界面行为 | 数据约束 |
|---|---|---|
| 科技树未加载 | 说明数据不可用，提供返回或重试 | 不创建虚构节点，不允许研究 |
| 余额不足 | 显示缺少资源，保留选中节点 | 不扣款、不模拟成功 |
| 装位冲突 | 指出冲突的装位与替换对象 | 由装备服务给出原因 |
| 接触失联 | 显示最后观测时间与陈旧状态 | 不自行更新位置 |
| 发射受限 | 显示缺解算、装填或深度等具体原因 | 不使用控件禁用替代权威再校验 |
| 存档失败 | 保留当前可恢复状态，允许重试或明确退出 | 不覆盖旧档、不宣称已保存 |
| 切换窗口或失焦 | 保持一致的暂停与输入释放策略 | 不留下持续转舵或发射按键 |
| 设置变更 | 可预览、应用和取消；高风险显示变更可恢复 | 设备设置不修改玩法状态 |

## 9. 尺寸、输入与无障碍

- 先验证 1920×1080 与 1280×720，再检查超宽屏和操作系统缩放；数值是测试视口，不是最低配置声明。
- 窄窗口收起次要面板、详情改为单层覆盖页；不把主要字体整体缩小解决拥挤。
- 固定工具栏、图标按钮和状态轨道尺寸，动态文字不得推挤核心布局。
- 中文长型号换行，数值有单位；不依赖颜色区分敌友、错误、选中与失联。
- 键盘焦点可见，弹窗有焦点约束，关闭后恢复原控件；鼠标捕获在港口和战斗间可靠切换。
- 键鼠绑定以当前输入配置为起点，新增或重绑定作为独立任务；这份界面文档不授权顺带改键。
- 音量分组、字幕、界面缩放、镜头震动与闪光强度提供设置；关键声音必须有对应可读提示。
- 手柄全流程和 Steam Deck 验证另行决定，不能因为单个轴可用就标注完整手柄支持。

## 10. 验收路径

UI-001：新档案 -> 教学 -> 港口 -> 选任务 -> 战斗 -> 战报 -> 研究 -> 重启恢复。
UI-002：鼠标和键盘分别完成研究与配装，记录真实点击/焦点反馈，不仅检查文字行存在。
UI-003：两种目标视口遍历长文本、空态、错误、模态与暂停，无遮挡主要玩法目标。
UI-004：隐藏接触切换视图、选中和发射提示，始终遵守授权信息边界。
UI-005：设置应用、取消、失焦、返回、保存失败后没有输入穿透和重复指令。

正式 UMG 制作前以本稿制作静态设计稿并评审；最终证据必须来自真实 UE4 编辑器和发布包，
不能用文字线框、网页原型或源码推断布局已经通过。

## 11. 输入动作提案

当前 `DefaultInput.ini` 只有航行/镜头轴映射。下表的离散动作均是 GAME-033 新提案，
不是复用旧产品按键的强制要求；未经批准不改输入配置。所有动作同时有可点击的正式入口。

| 输入 | 世界视图 | 战术图 | 潜望镜 | 港口/模态 |
|---|---|---|---|---|
| W/S | 提高/降低目标航速 | 同左 | 同左 | 不传给仿真 |
| A/D | 舵令，保留现有左右语义 | 同左 | 同左 | 不传给仿真 |
| Q/E | 保留当前深度轴语义，设置页以“更深/更浅”显示实际映射 | 同左 | 下潜超允许深度触发收镜 | 不传给仿真 |
| 鼠标移动/滚轮 | 环绕/缩放本艇镜头 | 拖动地图/缩放地图，不改变本艇航向 | 发送光学方位增量/倍率命令，Core 授权后呈现 | 普通指针/列表滚动 |
| Tab | 切战术图 | 回世界视图 | 切战术图，保留升镜状态提示 | 原生焦点遍历 |
| P | 请求升镜，到位后进入潜望镜 | 同左 | 请求收镜并返回先前视图 | 不执行 |
| Space | 主动声呐 | 同左 | 同左 | 仅焦点按钮激活 |
| F | 向选中合法接触发射一管 | 同左 | 同左 | 不执行 |
| R | 静默开关 | 同左 | 同左 | 不执行 |
| G | 发射一个诱饵 | 同左 | 同左 | 不执行 |
| Esc | 暂停 | 暂停 | 暂停 | 关闭最顶层可取消页；有草稿先确认 |

深度过大时 P 请求失败并说明条件，不替玩家自动上浮。升镜等待中允许取消；
切战术图不伪造潜望镜已收下，桅杆状态始终在本艇区可见。
同时按相反轴视为零；离散动作只响应按下边沿，不因系统按键重复持续发射。
首发没有战斗时间加速、自动航路、自动锁定真位置或一键最优规避。

## 12. 控件状态与事务表

| 控件/页面 | 正常可用条件 | 执行与反馈 | 禁用/取消/返回 |
|---|---|---|---|
| 启动“继续” | 有可恢复活动任务 | 装载后保持暂停，明确继续才运行 | 不兼容则进入恢复页，不用新规则硬读 |
| 港口“出航” | 合法档案、任务、艇与配装，无写入事务 | 单请求 ID；装载进度取真实阶段 | 缺条件显示原因；双击不创建两场 |
| 任务列表选择 | 只读公开元数据已装载 | 只改变简报草稿，不开场 | 未解锁项仅显示授权锁定元数据，不可选择出航 |
| 研究确认 | 预览结果可购买且版本未变 | 锁定同类动作，服务事务成功再扣款动画 | 余额/版本变化重新预览；取消不扣款 |
| 配装保存 | 有修改且整体合法 | 保存成功更新档案与模型 | 失败留草稿；返回有保存/放弃/继续编辑 |
| 接触选择 | 该公开接触尚未移除 | 当前接触详情与解算刷新 | 接触消失清空选择；不会选同位置另一隐藏目标 |
| 发射 | 合法接触、解算、深度、管位、弹药 | 服务再次校验，成功一次声音和库存变化 | 拒绝原因显示短反馈，不消耗资源 |
| 暂停“继续” | 无阻塞错误、保存或确认框 | 清轴与边沿，再恢复下一个 tick | Esc 关闭设置后仍暂停 |
| 暂停“保存退出” | 当前状态可序列化 | 保存中禁止重复动作，成功才退出 | 写失败留暂停，显示重试/明确丢弃未保存进度退出 |
| 中止确认 | 正在运行或暂停的非终态任务 | 确认产生中止事务、零收益 | 取消回原暂停状态，不自动继续 |
| 战报“再次出航” | 结果已提交且对应版本可用 | 新实例，相同种子/冻结配装 | 未提交禁用；数据变更回简报重新确认 |
| 重置生涯 | 港口，无活动任务或写入 | 二次确认、输入“重置”、备份成功后新档 | 任一步取消不删旧档；备份失败拒绝重置 |

确认框按钮位置固定，危险确认不默认获得焦点。保存失败不是自动放弃保存的授权。
后台操作采用请求 ID 和取消代数；离开页面后旧响应只释放资源，不改变新页面状态。

## 13. 模态、焦点与错误优先级

优先级：阻塞数据/存档恢复 > 终态待提交 > 保存中 > 危险确认 > 暂停/设置 > 普通详情 > HUD 通知。
只呈现一个交互模态；低优先级消息合并进事件日志，不把多个确认框叠在一起。
终态到来关闭普通详情和暂停子页；不打断正在执行的持久化事务，而是排队提交结果。
Esc 只处理当前顶层一次，不同时关闭窗口并恢复游戏。鼠标点击不能穿透模态到发射或出航按钮。
失焦立即请求在 tick 边界暂停，清除按下态和镜头捕获；回焦停在暂停菜单，不自动运行。
操作系统挂起/恢复、候选 Steam 覆盖层等同失焦策略，重复暂停请求幂等。

错误文字包含玩家可理解的原因与可执行动作；本地日志保留技术错误码和版本，不把隐藏舰坐标
输出到玩家可读战斗日志。一次错误不循环弹窗；恢复成功移除对应错误状态。
无错误对象的“重试”不可显示。未装载的分类、资源或统计使用空态，不猜测为零或假解锁。

## 14. 设置、重绑定与安全回退

设置分显示、音频、操作、无障碍；所有改动先保留草稿，应用成功才持久化。
画面质量、显示模式和界面缩放不改变仿真或任务难度。游戏难度仅在新出航简报选择，首发默认标准。
分辨率/全屏变更提供 15 秒本地墙钟确认；超时或失焦回原有效显示设置，此墙钟仅用于 UI 安全。
重启发现上次显示变更未确认，使用最后确认配置；连启动都失败时安全模式为窗口化 1280×720。
音量滑条实时预览，取消恢复旧值；设备拔出切系统默认设备，保留分组音量，不崩溃或暂停计时错误。
界面缩放提供 100%、125%、150%；高缩放切紧凑布局，不缩小文字抵消用户选择。
闪光与镜头震动可单独关闭，语音/音效/环境/音乐/主音量分组，字幕默认开。

重绑定等待一个有效按键，Esc 取消；冲突显示“交换 / 取消”，不静默覆盖另一个动作。
保留 Esc 作为模态返回安全键，不能绑定到发射；不接受系统保留组合。恢复默认需确认。
UI 设置键和战斗键上下文分离；同键在菜单按下不在关闭菜单后补发为战斗动作。
中文/英文若获批准可即时切换，未翻译文本用发行允许的回退语言，不显示内部键名；
简体中文未覆盖的关键流程阻塞首发，不用回退掩盖。

## 15. 视觉令牌与 UMG 布局尺寸

以下为设计值，不是渲染截图。基础单位为 1080p 的 UMG 逻辑像素，由 DPI 规则和用户缩放统一处理。

| 类别 | 定义 |
|---|---|
| 颜色 | 背景 #15191C；面板 #23282C；主文 #EEF2F3；次文 #BAC3C8；交互 #45C7CB；警告 #E3B64C；危险 #E86969 |
| 字体 | 使用随包分发且许可已核验的中文无衬线；关键数值等宽。许可未核验前不绑定外部字体 |
| 字级 | 页面标题 28，区域标题 22，正文 18，辅助 16；常规字距 0，禁止用细小字塞满界面 |
| 间距 | 基准 8；内部 16；页面安全边距 24；窄窗边距 16 |
| 形状 | 重复项目/模态圆角 4；主体页面不包浮动卡片；选中 2 像素线与符号双编码 |
| 操作 | 常规命令高度 44，图标按钮 44×44；数值/模式使用输入、滑条、分段或菜单，不全用文字胶囊 |
| 反馈 | 普通过渡 120 ms，可减少动态效果；危险操作不依靠动画时长保护事务 |

1920×1080：顶部 56 高、底部工具区 88 高、接触详情宽 288；本艇状态在左下，不占满左侧。
1280×720 或高缩放：隐藏常驻次要日志，详情一次只开一个系统；模态宽不超过视口减两倍边距，
内容可滚动、操作区固定，按钮不能滚出视口。战斗中央主要观察区域尽量保持不低于可用宽度 55%；
达不到时详情转暂停覆盖页，而不是继续遮挡主要目标。具体观感必须在编辑器验证后定稿。
鼠标悬停有短提示，名称、禁用原因和键绑定可从设置读取；不能让提示框越过屏幕边缘。
所有状态区为固定轨道，数值和翻译长度变化不推移按钮。模型、背景、图标均使用合法本地资产。

## 16. 逐页交付范围
