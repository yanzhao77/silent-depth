# 战斗系统规格

版本：0.2；日期：2026-09-14；性质：详细规则提案，数值与字段尚未落入生产配置。
实施前确认 GAME-010、GAME-011、GAME-014；架构见 [技术契约](07_TECHNICAL_ARCHITECTURE.md)。

## 1. 统一规则

- 所有战斗事实由 C++ 仿真产生；UE Actor、碰撞回调、摄像机和音频不能裁决结果。
- 固定步进暂沿用现有 20 Hz；仿真时间、输入顺序与随机流参与确定性基线。
- 仿真领域统一使用 km、秒、度；深度使用 m，显示航速使用 kt，转换在明确边界执行。
- 配置必须有版本、单位和范围校验。下文概念字段是设计契约，不假装代码已经定义。
- 无真实资料的型号能力使用明确的游戏化数值，不宣称为现实军用性能。

## 2. 航行与核潜艇资源

| 内容 | 拟定规则 |
|---|---|
| 输入 | 目标航速、方向舵或明确航向命令、目标深度、静默开关；新增控制需单独输入评审 |
| 权威状态 | 位置、航向、实际与目标速度、深度、转向和下潜过程、船体、噪声、剩余弹药与反制 |
| 主要取舍 | 更快机动产生更高辐射噪声与更差自噪监听条件；静默限制可用机动能力 |
| 深度 | 有水面、潜望镜和水下战术区域；具体边界由平台与海域数据给出，不沿用历史五层数值 |
| 核潜艇续航 | 正常任务中不使用通用电池耗尽强制上浮；压力来自时间窗口、暴露、弹药、损伤与阵位 |
| 限制反馈 | 无法达到的深度或速度返回可公开的原因；地图边界和危险水深明确反馈 |

不为替代电池条而新增虚构的“反应堆能量条”。常规潜艇若未来加入，再设计独立动力能力，
不要让所有艇带一套无意义的资源 UI。静默切换不能瞬间清除敌方已有接触。
地形水深参与规则时必须由离线海域数据查询，不能读取渲染海底网格反推。

## 3. 声呐与接触

每条接触区分观测、估计和确认；显示精度不得高于数据证据。

| 观测来源 | 可公开内容 | 不能隐含提供的内容 |
|---|---|---|
| 被动监听 | 方位区间、信号强弱、观测时刻、可推断分类与置信度 | 真实位置、精确距离、敌方内部状态 |
| 主动声呐 | 经规则产生的方位与距离区间、测量时刻 | 全知锁定、无限期精确跟踪 |
| 潜望镜 | 合法光学观测产生的类型、方位和估计信息 | 遮挡后的目标、任意精确距离、实时内部速度 |
| 多次跟踪 | 有足够观测几何时的航向、航速与距离估计区间 | 只等待固定时长就自动得到真值 |
| 失联 | 最后有效信息及陈旧程度，随规则扩大不确定性 | 继续贴着真实敌舰移动的图标 |

被动目标运动分析需要来自自身机动和多个时刻的观测；观测几何不足时保持方位接触。
第一切片可以只支持被动方位与主动测距，不以假距离填满界面；扩展分析算法须另补测试。

接触状态建议：初获 -> 跟踪 -> 陈旧 -> 丢失。分类置信度与解算质量为独立维度，
不因“分类正确”就授予距离真值。关联、衰减和移除由仿真决定，UI 不自行合并目标。

主动发射同时生成可被敌方传感器观测的声学事件；是否被探测仍由条件决定，不保证必然暴露。
不得无条件将玩家真实坐标发送给所有护航舰。

## 4. 火控

输入是玩家选择的公开接触与武器，不是隐藏实体 ID。火控只使用本艇状态和该接触的估计。
输出至少包括：解算是否可用、不可用原因、预计拦截区间、发射方向、信息陈旧程度。

建议状态：无解算、信息不足、条件可用、信息陈旧、发射受限。
首个版本不显示没有统计校准的“命中概率百分比”，用可解释的质量与限制信息。
玩家可接受合法但不确定的解算；不能因“没有百分百把握”一律禁止出手。
发射前再次在权威路径校验弹药、管位、装填、深度和所选接触，拒绝时不扣弹药。

## 5. 鱼雷与反制

首个现代武器建议采用“初始航段 -> 按预设条件启用寻的 -> 搜索 -> 跟踪 -> 再搜索或终止”。
先支持一个完整类型，不同时开发线导、反舰导弹、布雷和全部鱼雷变体。

- 弹药总量、发射管数量、可同时发射数与装填状态必须分别建模，不能相互代替。
- 传感器选择目标依据声学观测；诱饵是否有效由同一目标选择规则处理，不强制瞬间转向。
- 诱饵有有限数量、声学特征和生命周期；失效后不得保留声音、提示或权威目标。
- 鱼雷具有速度、转向限制、续航、保险条件和寻的参数，由配置决定。
- 命中使用确定性连续路径或扫掠检测，避免一固定步穿过目标；UE 碰撞只服务表现。
- 销毁、超时、命中及任务结束均清理实体；一次命中只结算一次伤害。
- 鱼雷不应自动知道最初目标的真位置；失去声学接触后必须进入搜索或终止逻辑。

近失、误判、诱饵吸引和失去目标要有可观察结果，但未被本艇听到或看到的事实不立即通报。

## 6. 敌方行为

| 状态 | 可用依据 | 行为方向 |
|---|---|---|
| 执行航线 | 自身任务、队形和合法导航数据 | 保持航线与护航位置 |
| 可疑 | 实际获得的噪声、主动声呐或威胁接触 | 调整监听和局部搜索，不直接指向玩家真位置 |
| 搜索 | 最后已知估计、观测时间与不确定范围 | 搜索可能区域并更新接触 |
| 攻击 | 自己的火控条件满足 | 使用受弹药和射击条件限制的武器 |
| 失联 | 观测超时或质量下降 | 扩大搜索后回归任务，不无限全知追踪 |

编队信息共享必须显式定义接触来源、延迟和共享内容，不共享全局真实敌表。
敌方潜艇复用信息权限与声学规则，不能直接继承玩家真实位置；其行为树或状态机只选择命令。
难度调整反应时间、搜索策略和编制，不开隐藏真值访问后门。

## 7. 损伤与威胁反馈

第一切片与首发均采用船体伤害、低船体噪声增加和毁损；机动/传感器子系统损伤延期。
不加入完整舱室进水、艇员伤亡、火灾和复杂损管，避免未定义的能力损坏状态进入首发。

毁损与能力下降由权威事件产生，表现不通过模型沉降或粒子反推死亡。
玩家威胁提示优先使用主动声呐入射、已探测武器和近爆报告，不默认显示敌方精确警戒条。
任何“已脱离”提示必须来自任务规则确认，而非镜头附近没有敌舰。

## 8. 最小回归矩阵

| 编号 | 场景 | 必须保持的性质 |
|---|---|---|
| CBT-001 | 同种子、同固定步输入，两次运行 | 快照摘要、事件顺序和最终结果相同 |
| CBT-002 | 被动接触但无测距；切换三视图 | 无精确点位、敌舰模型、尾迹或越权声音 |
| CBT-003 | 接触过期但敌舰仍移动 | 表现使用衰减估计，不追随真位置 |
| CBT-004 | 主动声呐范围内外分别测试 | 敌方按感知条件进入可疑，而非全部获知坐标 |
| CBT-005 | 同 tick 连续发射或管位受限 | 无负弹药、重复实体或绕过装填 |
| CBT-006 | 鱼雷高速经过目标、诱饵失效、任务终止 | 命中不穿透漏算，生命周期有界，无重复事件 |
| CBT-007 | 核潜艇长时间航行 | 不触发被淘汰的通用电池耗尽上浮规则 |
| CBT-008 | 暂停、恢复、保存续玩 | 不额外消耗弹药、计时或随机数，结果符合版本契约 |

首轮参数、公式、单位与确定样例集中在 [调参基线](13_TUNING_BASELINE.md)。
它们是待批准的游戏化测试起点，不是最终平衡或现实性能。

## 9. 命令有效性和同 tick 行为

每条命令按会话 ID、目标 tick、递增序号验证；旧会话、已处理序号和未来越界 tick 拒绝。
同 tick 的连续目标航速/深度采用序号最大的合法值；多个相反轴相抵为零，不由帧顺序选择。
发射、主动声呐、诱饵各允许一个有效边沿；其余同类边沿返回重复动作原因。
低编号可用管、库存、装填完成、深度与接触解算全部满足才扣库存并创建武器。
暂停期间边沿动作不排队，恢复后需要重新按键；装填完成与发射同 tick 以 tick 开始状态检查，
该步刚完成装填要等下一步才可发射。拒绝事件只向本艇公开，不生成声源。

## 10. 接触关联、分类与解算

原始观测含传感器类型、tick、方位区间及可选距离/深度区间、谱带证据。
内部发射源 ID 不进入玩家接触模型，不用它把被动估计悄悄校正成真位置。
新观测先与已有接触预测区间做门控：方位区间必须相交，有距离的双方还要求距离区间相交。
一轮按“归一化方位残差 + 可用的归一化距离残差”升序进行一对一匹配，等分取旧接触 ID；
未匹配则新建接触。一个接触不会因同一轮的两个来源自动获得两个目标的位置。
歧义只选匹配结果作为估计，不声称确认；UI 的选择跟随接触 ID，不跟随隐藏实体 ID。

带距离观测形成估计二维位置；两次相隔至少规定时间的观测才推导线性航速和航向，
估计速度超物理配置上限则解算无效，不通过夹紧伪造精确解。纯被动目标运动分析延期到首发后，
首发不以等待时间生成距离；这使被动监听与需要主动/光学测距的攻击存在明确取舍。
重新获得丢失目标通常形成新接触 ID，旧选择清空；陈旧但未丢失的合法关联保留选择。

火控使用估计相对位置 `r`、目标速度 `v`、鱼雷速度 `s`，求
`(dot(v,v)-s*s)*t*t + 2*dot(r,v)*t + dot(r,r)=0` 的最小正根。
二次项近零时解一次方程；无正根、根超过续航或缺距离/运动估计均拒绝解算。
初始发射方向为 `r+v*t`；深度是观测区间中值，目标水面分类可使用公开的水面事实。
区间质量展示通过端点组合计算范围，不宣称统计命中率。数值退化阈值在实现配置中固定并测试。

## 11. 环境、越界与碰撞

海域是有边界的离线水深栅格，未知样本当不可航行。地形单位和坐标见内容目录。
命令深度超过本艇上限或当前安全水深时拒绝；航行中海底抬升导致触底，按每 tick 连续伤害，
发出本艇危险反馈并允许玩家上浮或减速，不瞬移到安全位置。
陆地/水面舰船运动采用权威代理扫掠；本艇与舰船相撞，每个重叠接触段双方各受 20 伤害一次，
分离至少 1 秒后再接触才可再次计伤，不把同一段重叠按每帧扣伤。
鱼雷撞地形终止；保险前撞到舰船也终止但不伤害。实体销毁只结束自身，不引发范围连爆。
离开允许区域启动越界计时，回到边界内立即清零；在外超时以失去行动区域控制判负。
贴边行驶不会反复触发 UI 通知；只在状态变化时发布事件。

## 12. 护航反潜与敌潜艇

首发护航只用舰载轻型声学自导鱼雷，不同时增加深水炸弹、直升机和航空投放。
舰载反潜发射要求本舰接触带距离和深度估计；可疑方位只能搜索，不能直接攻击。
水面主动声呐可生成有界深度区间，误差为 20 m；超过海域水深或非有限区间的观测拒绝。
敌潜艇遵守同一感知、火控、库存和暂停规则；自己的任务脚本能给巡逻点，不能给玩家坐标。
护航保护运输船的行为可用友方航路与位置；共享给同编队的是测量及时间而非敌方真状态。
弹药耗尽的护航继续搜索或护送，不生成无限武器；敌潜艇弹尽后返巡逻区域。

每次 AI 决策按“已感知近距武器规避 > 合法攻击 > 有接触时补主动测量 > 搜索 > 原任务”选择。
有本舰合法武器接触且距离估计上界不超过 1.5 km 时，先选与入射方位垂直的可航行方向，
两个方向都可行则固定选顺时针一侧；有合法诱饵能力且冷却结束则发一个，没有则只机动。
规避状态维持至武器接触丢失，不使用武器真位置判断安全；舰载护航默认没有诱饵，敌潜艇有 3 个。
非规避时，有可疑/跟踪接触但无合格解算则在主动冷却结束后请求一次测距；
形成合法解算且反应延迟/装填/库存满足时发射一枚，之后仍受发射间隔约束。
AI 遵守同一武器与接触规则，不在决策函数里直接创建命中或伤害；事件和命令仍到下一 tick 执行。

## 13. 毁损和异常裁决

本 tick 先汇总全部有效伤害再判断毁损，实体只产生一次毁损事件。
同 tick 本艇与主要目标毁损按任务失败优先；统计可记录本艇已感知的战果，但不发胜利收益。
战斗终态冻结后丢弃后续命令，停止武器与敌舰推进；结果事件不能被暂停或切镜头撤回。
算法遇到非法数值或缺关键数据时暂停会话并保留最近安全检查点，记录本地诊断，
不把错误替换为命中、零伤害胜利或自动返港。用户可恢复有效检查点或中止。

## 14. 规格验证

场景 SCN-031 至 SCN-050 对本章规则逐项定义输入与预期；以矩阵为扩展回归清单。
特别验证两个接触方位交叉、对称火控无正根、保险阈值两侧、诱饵同分、
鱼雷先撞地形后到舰船、触底持续重叠、边界往返、同 tick 双方毁损和暂停时发射。
