# 任务与教学设计

版本：0.2；日期：2026-09-14；性质：详细任务规则提案。
本文件使用新任务编号，不自动复用现有配置里的历史 M01–M05。

## 1. 内容结构

教学教授判断方法，正式行动检验不同约束，复玩变体提供可重复挑战。
首发数量候选集中在 [产品范围](00_PRODUCT_SCOPE.md)，本文件不增加额外配额。
任务不会按墙钟、登录日期或服务器状态刷新；正式任务和变体均有明确版本与种子。

## 2. 三段教学建议

| 编号 | 核心技能 | 任务行为 | 通过依据 |
|---|---|---|---|
| TRN-01 | 航行与监听 | 调整航速，获得并选择接触，观察方位区间 | 权威记录满足教学步骤，不检查按钮文字 |
| TRN-02 | 阵位与攻击 | 获取足够信息，选择武器，完成一次合法攻击 | 发射与目标状态事件；不要求固定镜头操作 |
| TRN-03 | 反制与脱离 | 面对有限搜索，使用航行或反制脱离 | 任务撤离条件真实满足 |

教学可暂停、重试和从港口重新进入；提示与语音可关闭，关键事实保留字幕。
不要在接敌时展开长篇说明。正式教程文案在界面实现任务中另行评审，不用文档段落填满 HUD。
步骤触发必须来自状态与事件；不能以预期时间到了就宣布玩家已经学会或命中。

## 3. 首个完整切片：OP-001 运输线截击

此任务是开发验证任务，批准和验证后才决定是否进入正式内容。

| 项 | 初稿定义 |
|---|---|
| 玩家 | 一艘接入已验证的攻击潜艇，固定合法基础配装 |
| 敌方 | 一艘指定运输目标、一艘护航水面舰；不先加入敌潜艇和航空反潜 |
| 开局 | 玩家在可合理获取接触的外侧阵位，不处于必死交叉火力中 |
| 已知情报 | 行动区域、预计通过方向与时间窗口、目标描述、可能有护航 |
| 主要目标 | 阻止指定运输目标完成通过，初版以确认击沉为达成条件 |
| 次要目标 | 不使用主动声呐完成，或控制弹药消耗；只能选择已支持的目标谓词 |
| 胜利 | 主要目标达成后，进入撤离区域并满足脱离条件 |
| 失败 | 玩家艇毁损，或目标在主要目标未达成时离开任务区域 |
| 主动中止 | 结束本场且不计胜利；收益按经济决策执行，界面提前说明 |
| 结束后 | 战报 -> 一次可负担研究 -> 保存 -> 再次出航验证能力变化 |

具体位置和编制见 [内容目录](15_CONTENT_CATALOGUE.md)，计时与资源见
[调参基线](13_TUNING_BASELINE.md)。数据尚需实际制作并验证，文字不证明任务可完成。

### 3.1 事件推进

1. 装载任务、冻结配装并产生任务实例 ID。
2. 发布行动目标和已知情报；世界根据固定种子初始化。
3. 本艇获取声呐接触，玩家选择继续监听、机动或主动测距。
4. 武器发射后，护航按自己的观测决定是否搜索与攻击。
5. 仿真确认主要目标完成，公开任务阶段变更与撤离目标。
6. 满足撤离条件后冻结结果，执行一次结算事务；保存成功后进入港口。

### 3.2 撤离规则的候选表达

进入撤离区域 + 所有存活敌方对本艇的有效跟踪均已失效，连续保持 30 秒。
重新被有效跟踪、离开撤离区域任一发生就清零，不暂停保留进度；暂停游戏则冻结进度。
“有效跟踪”是敌方当前非陈旧接触，不要求对方精确定位；无任何敌方跟踪时条件自然满足。
规则属于任务核心，可以读取其需要的权威事实；UI 只得到“撤离进行中 / 已完成”等授权结果，
不得暴露敌方搜索坐标或剩余内部计时。每个任务必须定义无法撤离时的明确原因。

## 4. 后续任务类型

| 类型 | 主要变化 | 依赖 |
|---|---|---|
| 运输线截击 | 目标编制、护航位置、时间窗口 | 基础声呐、鱼雷、护航行为 |
| 隐蔽侦察 | 识别或观察指定对象后返回，禁止或限制交战 | 可靠观测与分类事件 |
| 封锁突破 | 到达区域且满足生存或隐蔽约束 | 地图约束、公平搜索与撤离 |
| 潜艇猎歼 | 在双方信息不完整的条件下搜索和交战 | 敌潜艇行为、声学自导与反制完整验证 |

不要以改任务名字、换天气和提高敌人血量冒充全新任务类型。
新任务至少改变一项战术选择，并有完整的失败、退出和结束路径。

## 5. 难度与复玩

- 第一批任务逐步增加单一主要压力：信息不足、护航反应、行动窗口、敌潜艇。
- 参数变化只通过有版本的任务配置；同任务版本、种子、配装和输入能复现。
- 复玩采用已校验模板与有限种子集合；初版不承诺任意种子生成都可完成。
- 不在玩家看不到时临时增加敌军；任务变体必须与简报中的情报质量相符。
- 高难度不允许敌人越过传感器规则；奖励增长需与时长和失败风险一起评估。

## 6. 单任务交付模板

每个任务数据包必须附带：任务 ID 与版本、所属海域、支持平台能力、初始资源、
公开简报、实体生成规则、敌方行为参数、主要与次要目标谓词、胜负与撤离条件、
种子集合、结算引用、资产依赖、教程事件、本地化键、自动化样例与人工试玩记录。

目标引用必须验证存在；所有必需资产和规则参数装载成功才能开始。
某目标无法在当前系统表达时应拒绝发布该任务，不能在 UMG 中猜测目标达成。

## 7. 验收

| 编号 | 检查 | 预期 |
|---|---|---|
| MSN-001 | OP-001 胜利、失败、中止各跑一次 | 唯一终态、原因正确、一次结算 |
| MSN-002 | 最后目标事件与玩家毁损同 tick | 按已定义的事件裁决顺序给出唯一结果 |
| MSN-003 | 目标生成失败或必要配置缺失 | 装载失败关闭，不出现“无敌人即胜利” |
| MSN-004 | 教学跳过、重进、失败重试 | 不重复发放初始奖励，不阻塞正常出航 |
| MSN-005 | 任务接敌与撤离人工试玩 | 无长时间无决策空档、不可达目标或隐性必败 |
| MSN-006 | 不同种子与配装的内容回归 | 记录实际可完成样例，不用单个脚本胜利代表全部组合 |

同 tick 裁决提案采用玩家毁损优先于普通胜利，具体裁决如下；实施前通过 GAME-030 批准。

## 8. 终态优先级与边界

| 发生条件 | 本 tick 处理 | 后续行为 |
|---|---|---|
| 玩家毁损与目标击沉同时发生 | 先汇总伤害，再判玩家失败 | 只一次结果，无胜利或首次奖励 |
| 目标被击沉与抵达离区线同时发生 | 同步伤害后的毁损目标计已达成，不再作为离区失败对象 | 玩家仍需撤离 |
| 总时限到达且撤离刚满 | 时限失败优先 | 不因 UI 动画先完成而胜利 |
| 暂停请求与目标毁损同 tick | 若该 tick 已开始就完整裁决，终态优先于进入暂停 | 结果待提交，不再恢复战斗 |
| 中止确认与尚未开始的 tick | 先结束会话为中止，不再推进该 tick | 零收益；不产生最后一帧攻击 |
| 同 tick 多个主要目标变化 | 批量更新谓词后只计算一次终态 | 不在遍历首个实体时提前胜利 |
| 弹药耗尽但主要目标未完成 | 不判负；在航鱼雷仍可能达成，玩家可等候或中止 | 提示弹药状态，不猜测剩余成功概率 |
| 全敌已毁损但未进撤离区 | 主要目标已达成则允许无跟踪条件撤离 | 仍需到区保持，不无条件瞬移返港 |
| 未完成主要目标就进撤离区 | 不开始撤离计时 | 显示目标未完成；突破任务例外由初始目标声明 |

总优先级为：玩家毁损、主要目标不可达、越界超时、总时限、撤离成功；唯一原因取第一项。
主动退出不进入此表，按会话保存/中止协议处理。所有时限使用仿真 tick，暂停不消耗。

## 9. 教学与任务进度

教学步骤分为可锁存事实（已观测、已合法发射）和持续条件（低速保持、撤离），前者允许提前完成，
后者只在其自身条件成立时计时；切视图不重置观测。先做后教时直接推进，不要求再做一次。
重试恢复该段初始配置，不保留借用装备或临时目标；跳过只标跳过，不伪造通过成绩。
正式行动按标准任务首次胜利顺序开放，变体/教学不越级开放后续正式任务。
当前任务 ID 缺失或更新后被移除时保留历史统计，入口显示不可用，不自动选择另一关继续。

## 10. 任务装载与中途故障

装载必须验证目标实体、航路、水深、初始资源、撤离区域、时间窗口、模板版本和能力需求。
取消装载先撤销请求标识，晚到的异步结果直接释放；不会在用户返回港口后突然进入战斗。
主目标配置为空不能解释成“没有目标所以胜利”；错误停在简报并返回具体配置项。
运行中必需数据异常暂停保存错误快照的诊断但不把非法状态写为可续玩检查点；
允许恢复最近有效检查点或中止，不能自动报任务完成。
全体敌人因数据装载缺失与全体敌人被合法击沉是不同状态，必须各有测试。
