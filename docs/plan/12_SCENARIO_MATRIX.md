# 首发场景覆盖与验收矩阵

版本：0.2；日期：2026-09-14；性质：100 个明确用例的规格清单，不是运行测试报告。
本表覆盖当前提议的首发范围、关键异常与候选平台功能的开/关行为，不声称穷尽所有参数组合。
所有用例的 UE、编辑器、发布包和硬件执行状态均为 `NOT VERIFIED`。

## 1. 使用规则

每行定义前置状态、触发、唯一预期、持久化影响、规格责任与实施任务。
“不写”是没有长期状态提交；战斗内仍可按规则推进临时权威状态。“整档”指存档协议的 A/B 完整提交。
规格简称为本目录编号，例如 `05 §10` 指成长规格第十节，`14` 指存档恢复协议。
场景 ID 就是该验收用例的唯一 ID，未来映射到真实测试类/输入文件；不能把一个泛化测试名当执行证据。

验证方式：启动/界面组需 UE 实际操作；战斗组先纯 C++ 固定输入后编辑器；存档组做故障注入；
资源/发行组做发布包和具名设备测试。每行保留版本、初始档案、seed、步骤、实际结果和证据路径。
当前没有这些执行证据，不填“通过率”。设计变更必须同步本表预期，不能只改代码或删除失败用例。

## 12. 组合覆盖与数据规模

上述单场景之外，下列组合是固定的发布回归组，不能只各自单测后推断组合安全：

| 组合 | 叠加条件 | 共同预期 |
|---|---|---|
| COM-01 | 失焦 + 发射边沿 + 暂停恢复 | 不补发，不补走仿真时间 |
| COM-02 | 同 tick 双方毁损 + 结果保存失败 + 重启 | 唯一失败，按最近持久化阶段恢复，零胜利奖励 |
| COM-03 | 自动检查点写入 + 终态 + 关闭窗口 | 提交严格串行，旧快照不能覆盖结果 |
| COM-04 | 窄窗口 + 150% 缩放 + 中文长文本 + 恢复错误模态 | 主要操作可见可达，焦点不穿透 |
| COM-05 | 更新后活动任务不兼容 + 云分叉 | 长期档案完整选择，活动任务明确放弃，不热升级续玩 |
| COM-06 | 接触交叉 + 丢失 + 切视图 + 发射 | 不借隐藏 ID 重选目标，不发生越权显示 |
| COM-07 | 舰船/鱼雷/接触容量边界 + 连续重开 | 拒绝/淘汰遵守规格，不负库存，不持续资源增长 |
| COM-08 | 初始档案 + 跳过教学 + 首次研究 + 全行动路线 | 无资源死锁，初始授予与首次奖励均不重复 |

正式内容每关 5 个变体静态校验；每关标准种子要有胜利/失败证据。
跨艇、天气、观察模式与画质组合使用成对组合覆盖，保存、结算、隐私边界采用指定的强制全组合。
精确组合列表在测试工单随最终内容版本生成并固定，不能以随机抽查替代必测组合。

## 13. 范围之外

多人、在线经济、创意工坊、自由航路、反应堆、航空反潜、战略导弹、全知回放、
自动时间加速和多生涯 UI 不在本提议首发范围。新增它们需要新增规格、场景与预算，不能默认为已覆盖。
本矩阵描述预期，不承诺 UI 美术稿、最终平衡、真实 UE 运行或 Steam 流程已经完成。
