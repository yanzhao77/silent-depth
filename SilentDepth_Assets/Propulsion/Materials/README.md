# Materials（共用材质）

推进系统资产默认使用程序化 PBR 参数，不依赖外部贴图（与 Typhoon 母版的 `Propeller` 材质保持一致）。

| 材质名 | 基准色（线性） | 粗糙度 | 金属度 | 用途 |
| --- | --- | ---: | ---: | --- |
| `M_Propulsor_Blade` | 0.250, 0.180, 0.075 | 0.43 | 0.84 | 桨叶、泵喷转子（青铜） |
| `M_Propulsor_Hub` | 0.190, 0.230, 0.250 | 0.40 | 0.82 | 轮毂、桨轴、定子 |
| `M_Propulsor_Duct` | 0.105, 0.130, 0.145 | 0.64 | 0.35 | 导管、泵喷外壳、整流包 |
| `M_Propulsor_Rubber` | 0.018, 0.027, 0.035 | 0.83 | 0.08 | 消声覆层、导管内衬 |

规则：

- 每个网格必须挂材质，缺材质视为校验失败。
- 不允许出现名为 `Material` 的默认材质。
- 贴图是可选增强：只有在真的提供本地贴图文件时才在清单里声明，并记录来源与 SHA-256。
- 本项目不使用任何在线贴图或 CDN 资源，运行时保持完全离线。

对应的 UE4.27 材质命名参考 Typhoon 资产已经建立的 `M_PropellerBronze` / `M_SubmarineHull` 体系。
