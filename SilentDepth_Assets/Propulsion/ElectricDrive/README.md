# ElectricDrive（电力推进）— DATABASE_ONLY

电力推进在游戏科技树里是 T6–T10 的世代标签，本目录不产出独立 3D 资产。

公开层面的内容：

- `PC_ELECTRIC_DRIVE`：电力传递推进能量，减少或取消机械齿轮箱。
- `PC_INTEGRATED_ELECTRIC_PROPULSION`：核动力装置 → 涡轮发电机 → 电力推进电机 → 轴系。
- `AUX_RETRACTABLE_PROPULSOR`：可收放辅助电力推进器（Akula 级公开资料明确提到两具），
  对应的可视化资产是 `../Thrusters/` 下的推进槽。

数据来源：`../Documentation/research/powerplant_research.json`。
