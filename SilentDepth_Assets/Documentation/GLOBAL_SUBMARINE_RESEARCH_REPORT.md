# Global Submarine Research Report

Generated: 2026-09-08

This is an initial open-source planning database for Silent Depth visual assets. It is not a military research product and does not define combat balance, sonar behavior, physics, AI, or real-world classified performance.

## Findings

- The seed list was expanded into SSN and SSBN production records across USA, Russia/Soviet Union, UK, France, China and India.
- Variants are not treated as independent full models unless visible game-distance differences justify that work.
- Virginia Block V, Yasen-M and Borei-A are marked as heavy variants or independent assets because the overall silhouette or payload section can differ visibly.
- Type 093B, Type 095, Type 096, S4, S5, SSN-AUKUS, Columbia, UK Dreadnought and SNLE 3G retain limited or planned-data status where appropriate.
- Unknown or insufficiently verified measurements are stored as `UNKNOWN`, not invented.

## Current Production Reality

Typhoon has local Blender/FBX/LOD/preview/validation assets and is the current master source candidate. It remains `VALIDATING` until UE4.27 editor import is actually run or an approved local validator accepts Blender FBX roundtrip as sufficient for this pipeline stage.

All non-Typhoon submarines are directory and research slots only. They are not completed assets and contain no fake geometry.
