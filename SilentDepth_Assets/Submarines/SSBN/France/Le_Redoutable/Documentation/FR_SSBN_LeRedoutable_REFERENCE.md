# FR_SSBN_LeRedoutable Le Redoutable（可畏级 / 法国第一代 SSBN）

> 资料状态：【已有】资料文档【缺失】模型【待建模】・最后更新：2026-09-11

## 1. 身份与定位

- 国家：法国（Marine nationale）
- 艇型：SSBN（法国称 SNLE）
- 级：**Redoutable class**（可畏级，1967 年版）
- 定位：**法国第一代弹道导弹核潜艇**
- 前型：无；后型：Le Triomphant class
- 同级 6 艘，首艇 *Le Redoutable* 现作为博物馆展出

## 2. 尺度与外形

| 项目 | 数值 |
|---|---|
| 全长 | 128 m（419 ft 11 in） |
| 艇体宽 | 10.6 m（34 ft 9 in） |
| 吃水 | 10 m（32 ft 10 in） |
| 排水量（水下） | 8,000 t |

外形特征（面向建模）：

- 法国 SNLE 的经典外形：**围壳靠前、围壳舵、单轴螺旋桨 + 十字艉舵**。【待建模】
- 围壳后方为 **16 具 M4 导弹发射筒**的隆起段。【待建模】
- 艇体为长水滴形，艏部圆钝。【待建模】
- **法国潜艇的围壳外形与世界其他流派差异明显**（较短、顶部桅杆布置紧凑），
  建议以首艇 *Le Redoutable* 的博物馆照片为建模主参考。【待确认】
- 【待确认】消音瓦情况：本级后期艇有降噪改装。

## 3. 动力

- 反应堆：**1 × 压水堆（PWR）**
- 轴功率：**16,000 shp（12,000 kW）**
- 燃料：高浓缩铀（HEU ≤ 90%）【待确认】
- 航速：**超过 20 kn（37 km/h）**
- 续航：无限距离，**堆芯寿命 20–25 年**

## 4. 武备

### 弹道导弹

- **16 具 M4 MSBS（Mer-Sol Balistique Stratégique）潜射弹道导弹发射筒**
- M4 弹长：约 11.0 m；直径 1.93 m【待确认】
- 【缺失】发射筒尺寸与筒盖外形
- 【待确认】早期艇是否使用 M1/M2/M20 导弹（本级随年代多次换装）

### 鱼雷与反舰

- **4 具 533 mm（21 英寸）鱼雷发射管**
- 可用弹种：**F-17 与 L-5 鱼雷**、**SM-39 Exocet 反舰导弹**
