# FR_SSBN_LeTriomphant Le Triomphant（凯旋级）

> 资料状态：【已有】资料文档【缺失】模型【待建模】・最后更新：2026-09-11

## 1. 身份与定位

- 国家：法国（Marine nationale）
- 艇型：SSBN（法国称 SNLE）
- 级：Triomphant class（凯旋级）
- 前型：Redoutable class；后型：SNLE 3G
- 定位：法国现役海基战略威慑平台，共 4 艘

## 2. 尺度与外形

| 项目 | 数值 |
|---|---|
| 全长 | 138 m（453 ft） |
| 艇体宽 | 12.50 m（41.0 ft） |
| 吃水 | 10.60 m（34.8 ft） |
| 排水量（水上） | 12,640 t |
| 排水量（水下） | 14,335 t |

外形特征（面向建模）：

- **围壳位于艇体前段，采用围壳舵**。【待建模】
- 围壳后方 **16 具 M45 / M51 导弹发射筒盖**。【待建模】
- **泵喷推进器**（K15 反应堆 + 涡轮减速泵喷-轴系）。【待建模】
- **十字艉舵**。【待确认】
- 艇艏 **4 具 533 mm 发射管**。【待建模】
- 法国式围壳外形（较紧凑，桅杆布置密集）。【待建模】
- 消音瓦覆盖，表面分块清晰。【待建模】

## 3. 动力

- 反应堆：**K15 压水堆，150 MWth**（低浓缩铀 LEU 7%）
- 推进：**涡轮减速泵喷-轴系（turboreductor pump-to-shaft），30.5 MW**
- 总功率：**30,519 kW（40,927 hp）**
- 辅机：2 台 SEMT Pielstick 8PA4V200 SM 应急柴油发电机（各 700 kW / 940 hp）
- 航速：**超过 25 kn（46 km/h）**
- 续航：无限距离，堆芯寿命 **20–25 年**

## 4. 武备

### 弹道导弹

- **16 具发射筒**
- 可用导弹：**M45** 或 **M51 / M51.3**
- 弹头：**TN 75（150 kt）** 或 **TNO（100–300 kt）** 热核弹头，每枚 6–10 枚分导
- 弹长：M45 约 11.0 m；M51 约 12.0 m【待确认】

### 鱼雷

- **4 具 533 mm（21 in）鱼雷发射管**
- 可用武器：F17 mod2 / F21 鱼雷、Exocet SM39 反舰导弹、水雷【待确认】
- 发射管长度：UNKNOWN【缺失】
