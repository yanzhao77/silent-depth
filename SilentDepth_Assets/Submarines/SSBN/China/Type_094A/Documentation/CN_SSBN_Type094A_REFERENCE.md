# CN_SSBN_Type094A Type 094A（094A 型）

> 资料状态：【已有】资料文档【缺失】模型【待建模】・最后更新：2026-09-11

## 1. 身份与定位

- 国家：中国（中国人民解放军海军潜艇部队）
- 艇型：SSBN（核动力弹道导弹潜艇）
- 型号：Type 094A（094 的改进型）
- 前型：Type 094；后型：Type 096
- 北约代号：仍归入 **Jin class（晋级）**
- 定位：094 的改进批次，据公开分析主要改进静音性能与导弹适配

> **重要**：本级与 Type 094 **同属一族、尺寸接近**。本项目的科技树把两者列为
> 两个独立资产（T9 与 T8），但**目前没有任何公开资料能支持两者做不同几何**。
> 建模前必须先确定可见差异，否则应共用母资产 + 变体。
