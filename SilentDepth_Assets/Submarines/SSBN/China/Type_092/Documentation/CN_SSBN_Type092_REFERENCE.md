# CN_SSBN_Type092 Type 092（092 型 / 北约代号 Xia 夏级）

> 资料状态：【已有】资料文档【缺失】模型【待建模】・最后更新：2026-09-10

## 1. 身份与定位

- 国家：中国（中国人民解放军海军）
- 艇型：SSBN（核动力弹道导弹潜艇）
- 级 / 型号：Type 092，中国代号 **09-II**；北约代号 **Xia（夏）级**
- 前型：Type 031（033G/Golf 级，常规动力弹道导弹潜艇）；后型：Type 094
- 建造厂：Bohai Shipyard（渤海造船厂），葫芦岛
- 舷号：**406**（本级唯一一艘）
- 时间线：1971-09 开工 → 1981-04 下水 → 1983-08 服役 → 2015 年前退役
- 现役状态：已退役
- 母港：Jianggezhuang Naval Base（姜格庄）

**本级是中国第一艘自行研制并服役的核动力弹道导弹潜艇**，只建造 1 艘，主要承担技术验证与威慑值班任务。【已有】公开照片与线图存在，但细节资料有限。

## 2. 尺度与外形

| 项目 | 数值 |
|---|---|
| 全长 | 120 m（393 ft 8 in） |
| 艇体宽 | 10 m（32 ft 10 in） |
| 吃水 | 8 m（26 ft 3 in） |
| 排水量 | UNKNOWN【缺失】 |

外形特征（面向建模）：

- **本级是 Type 091 攻击核潜艇加装导弹舱段的产物**——维基明确写 "essentially a Type 091 submarine with an added section for twelve JL-1 SLBMs"。因此两级的艏部、围壳与艉部外形高度一致，**模型可以共用大部分几何**，差异集中在背部导弹段。【待建模】
- **12 具 JL-1 导弹发射筒**布置在围壳后方的背部隆起段。【待建模】
- 围壳位于艇体前段，为苏式影响的窄高型。【待建模】
- 艉部为**单轴螺旋桨 + 十字舵**。【待建模】
- 艇体为长水滴形，艏部圆钝。【待建模】
- 早期中国核潜艇的**围壳开口与排水孔较多、表面不如美苏产品光洁**——这是识别特征，建模时不应过度"现代化"。【待确认】

## 3. 动力

- 反应堆：**1 座压水堆，功率 58 MW**
- 主推进：**2 台汽轮机 → 1 根轴**
- 航速：22 kn（41 km/h）
- 续航：无限

【缺失】反应堆具体型号与螺旋桨叶数未取得公开数据。
【待确认】维基提到"研制过程中提升了动力装置输出功率，相关改动后来被 Type 091 后续艇采用"，说明本级与 091 后期型在动力舱段上有对应关系。

## 4. 武备

### 弹道导弹

- **12 具 JL-1（巨浪-1）A 型潜射弹道导弹发射筒**。
- 发射方式：**燃气-蒸汽发生器弹射**（gas-steam generator）——该发射装置先在中国 Golf 级常规潜艇上做过试验。
- 弹长：约 10.7 m【待确认】——JL-1 为两级固体导弹，需按权威资料核对后用于筒段建模。
- 【缺失】发射筒直径与筒盖尺寸。

### 鱼雷

- **6 具 533 mm 鱼雷发射管**（本级管数多于同期苏制 667 系列）。
- 发射管长度：UNKNOWN【缺失】
- 载雷量：UNKNOWN【缺失】
- 常用弹种：中国制 533 mm 鱼雷（型号需核实）【待确认】

【不许推断】发射系统内部结构、火控与再装填机构不做还原。

## 7. 建模要点

1. 全长 120 m / 宽 10 m / 吃水 8 m 的整体比例。【待建模】
2. **与 Type 091 共用艇体几何**：艏部、围壳、艉部基本一致，差异是背部多出的导弹舱段。【待确认】
3. 围壳后方的 **12 具导弹发射筒盖**，沿中线前后排列。【待建模】
4. 单轴螺旋桨 + 十字艉舵。【待建模】
5. 艇艏 **6 具 533 mm 发射管**开口（比苏制 667 系列的 4+2 布局不同）。【待建模】
6. 围壳顶桅杆群与开口布置按实艇照片还原。【待建模】
7. 表面保留早期中国核潜艇的粗糙感：更多开口、排水孔与分段线，避免做成光滑的美苏风格。【待确认】
