# IN_SSBN_Arighaat Arighaat（歼敌者级二号艇）

> 资料状态：【已有】资料文档【缺失】模型【待建模】・最后更新：2026-09-11

## 1. 身份与定位

- 国家：印度（Indian Navy）
- 艇型：SSBN（核动力弹道导弹潜艇）
- 级：Arihant class（Arihant 子型）
- 艇名：**INS Arighaat**（歼敌者级第二艘）
- 前型：INS Arihant；后型：Aridhaman（S4）与 S5
- 建造厂：Ship Building Centre（SBC），Visakhapatnam

> **提示**：本级与 `IN_SSBN_Arihant`（T7）、`IN_SSBN_S4`（T9）同属 Arihant 级。
> Arighaat 与 Arihant **同子型、同尺寸**，两者外形基本相同；
> S4 属于放大的 Aridhaman 子型（130 m）。

## 2. 尺度与外形

| 项目 | Arihant / Arighaat |
|---|---|
| 全长 | 111 m（364 ft） |
| 排水量（水上） | 6,000 t |
| 艇体宽 | 11 m（36 ft） |

外形特征（面向建模）：

- 与 INS Arihant 相同：围壳靠前、围壳后方 4 具导弹发射筒隆起段、围壳舵、单轴螺旋桨。【待建模】
- **与 Arihant 的差异：无公开资料支持**。【缺失】——建议共用几何，仅在命名与涂装上区分。
- 艇艏鱼雷发射管开口。【待建模】
