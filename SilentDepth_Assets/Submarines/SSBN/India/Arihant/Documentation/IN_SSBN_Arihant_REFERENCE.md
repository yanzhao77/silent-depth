# IN_SSBN_Arihant Arihant（歼敌者级）

> 资料状态：【已有】资料文档【缺失】模型【待建模】・最后更新：2026-09-11

## 1. 身份与定位

- 国家：印度（Indian Navy）
- 艇型：SSBN（核动力弹道导弹潜艇）
- 级：Arihant class
- 建造厂：Ship Building Centre（SBC），Visakhapatnam
- 定位：**印度第一型自行建造的核动力潜艇**，构成印度"核三位一体"的海基支柱
- 计划 4 艘，已完工 4 艘，其中 3 艘在役（截至资料日期）
- 后型：S5 class
- 单艇造价：约 **400 亿卢比（4.2 亿美元）**
