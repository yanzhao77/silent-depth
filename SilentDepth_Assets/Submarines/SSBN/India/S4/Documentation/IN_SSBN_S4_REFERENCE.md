# IN_SSBN_S4 S4 / Aridhaman（歼敌者级放大子型）

> 资料状态：【已有】资料文档【缺失】模型【待建模】・最后更新：2026-09-11

## 1. 身份与定位

- 国家：印度（Indian Navy）
- 艇型：SSBN（核动力弹道导弹潜艇）
- 级 / 子型：Arihant class / **Aridhaman 子型**（第三、四艘）
- 艇名：**INS Aridhaman（S4）**，同级另有 Arisudan（S4*）
- 前型：Arihant、Arighaat（111 m 子型）；后型：S5 class
- 建造厂：Ship Building Centre（SBC），Visakhapatnam

> **本资产是 Arihant 级中放大的一型**（130 m / 7,000 t），
> 与 `IN_SSBN_Arihant`、`IN_SSBN_Arighaat`（111 m / 6,000 t）**有实质尺寸差异**，
> 可以独立建模。

## 2. 尺度与外形

| 项目 | **Aridhaman 子型（S4）** | Arihant / Arighaat |
|---|---|---|
| 全长 | **130 m（430 ft）** | 111 m |
| 排水量（水上） | **7,000 t** | 6,000 t |
| 艇体宽 | 11 m（沿用本级数据）【待确认】 | 11 m |

外形特征（面向建模）：

- **比 Arihant 子型加长约 19 m**，加长部分用于容纳更大的导弹（K-4）与更多发射筒。【待建模】
- 围壳位于艇体前段，围壳后方为导弹发射筒隆起段。【待建模】
- 围壳舵。【待确认】
- 单轴螺旋桨 + 十字艉舵。【待确认】
- 艇艏鱼雷发射管开口。【待建模】
