# IN_SSBN_S5 S5（印度下一代弹道导弹核潜艇）

> 资料状态：【已有】资料文档【缺失】模型【待建模】・最后更新：2026-09-11

## 1. 身份与定位

- 国家：印度（Indian Navy）
- 艇型：SSBN（核动力弹道导弹潜艇）
- 级 / 项目号：**S5 class**（代号取自"先进技术舰艇"系列后续型）
- 前型：Arihant class（歼敌者级：Arihant、Arighaat、S4 / Aridhaman、Arisudan）
- 建造厂：Ship Building Centre（SBC），Visakhapatnam
- 计划数量：**3 艘**【待确认】
- 状态：**规划/在建初期**，预计 2030 年代服役【待确认】

【缺失】本级是印度下一代 SSBN，公开资料极少，**大部分参数为推测**。

## 7. 建模要点

1. **与 Arihant 级逐条对照**（本项目有 Arihant / Arighaat / S4 资产）。【待确认】
2. 预计艇体显著放大（长度可能达到 160–170 m）。【推测】
3. 更大的导弹舱段与筒盖布置。【推测】
4. 推进器形式未知，**不要默认沿用 Arihant 级的螺旋桨**。【待确认】
5. **在取得公开影像前，本级应保持 `PLANNED`**。
