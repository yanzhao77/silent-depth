# US_SSBN_Lafayette Lafayette（拉法耶特级）

> 资料状态：【已有】资料文档【缺失】模型【待建模】・最后更新：2026-09-11

## 1. 身份与定位

- 国家：美国（United States Navy）
- 艇型：SSBN（核动力弹道导弹潜艇）
- 级：Lafayette class
- 前型：Ethan Allen class；后型：James Madison class → Benjamin Franklin class → Ohio class
- 定位：美国 SSBN 族中的"基准型"，后续三型（James Madison / Benjamin Franklin / 及改装艇）都在其基础上演进
- 同级 9 艘

## 2. 尺度与外形

| 项目 | 数值 |
|---|---|
| 全长 | 425 ft（130 m） |
| 艇体宽 | 33 ft（10 m） |
| 吃水 | 28 ft 6 in（8.69 m） |
| 排水量（水上） | 7,325 long tons（7,443 t） |
| 排水量（水下） | 8,251 long tons（8,383 t） |

外形特征（面向建模）：

- 与 James Madison、Benjamin Franklin 三级**尺寸数据完全相同**（130 × 10 × 8.69 m，7,325/8,251 lt），
  外形差异极小，建模时**必须以照片细节区分**而非尺寸。【待确认】
- 围壳位于艇体前段，带可收放**艏水平舵**。【待建模】
- 围壳后方 **16 具导弹发射筒盖**的隆起段。【待建模】
- **单轴螺旋桨 + 十字艉舵**。【待建模】
- 【待确认】本级为美国 SSBN 中首级引入某些降噪特征的型号，消音瓦范围需核实。

## 3. 动力

- 反应堆：**1 × S5W 压水堆**
- 主推进：2 台齿轮传动汽轮机，**15,000 shp（11,000 kW）**
- 轴系：单轴
- 航速：水上 16 kn（30 km/h）／水下 21 kn（39 km/h）

## 4. 武备

### 弹道导弹

- **16 具发射筒**
- 可用导弹：**Polaris A2 / A3**，后续换装 **Poseidon C3**
- Polaris A3 弹长约 9.86 m；Poseidon C3 约 10.36 m【待确认】

### 鱼雷

- **4 具 533 mm（21 英寸）鱼雷发射管**
- 载雷量：**12 枚**
- 发射管长度：UNKNOWN【缺失】

## 5. 传感器与电子设备

【缺失】型号清单未取得。典型配置为艇艏声呐 + 潜望镜 + 雷达；本级后期部分艇装备了拖曳阵。

## 6. 潜深与乘员

- 试验深度：**1,300 ft（400 m）**
- 编制：**两套艇员（蓝/金），每套 14 名军官 + 126 名士兵**

## 7. 建模要点

1. 全长 130 m / 宽 10 m / 吃水 8.69 m。【待建模】
2. **与 James Madison、Benjamin Franklin 三级的差异**是建模难点：三者尺寸相同，必须靠围壳细节、
   发射筒盖形状、消音瓦分块、天线布置等照片证据区分。【待确认】
3. 16 具导弹发射筒盖。【待建模】
4. 围壳舵 + 单轴螺旋桨 + 十字艉舵。【待建模】
