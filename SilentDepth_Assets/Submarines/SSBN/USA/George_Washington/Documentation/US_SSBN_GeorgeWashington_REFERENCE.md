# US_SSBN_GeorgeWashington George Washington（乔治·华盛顿级）

> 资料状态：【已有】资料文档【缺失】模型【待建模】・最后更新：2026-09-11

## 1. 身份与定位

- 国家：美国（United States Navy）
- 艇型：SSBN（核动力弹道导弹潜艇）
- 级：George Washington class
- 定位：**世界上第一级弹道导弹核潜艇**（由 Skipjack 级攻击核潜艇加装导弹舱段改装而来）
- 前型：无（本级为开创者）；后型：Ethan Allen class

## 2. 尺度与外形

| 项目 | 数值 |
|---|---|
| 全长 | 381.6 ft（116.3 m） |
| 艇体宽 | 33 ft（10 m） |
| 吃水 | 29 ft（8.8 m） |
| 排水量（水上） | 5,959 long tons（6,055 t） |
| 排水量（水下） | 6,709 long tons（6,817 t） |

外形特征（面向建模）：

- **在 Skipjack 级艇体中部插入导弹舱段**，围壳因此前移，围壳后方形成明显的**导弹舱隆起**。【待建模】
- **16 具 Polaris 导弹发射筒盖**沿中线前后排列。【待建模】
- 围壳上装有可收放艏水平舵。【待建模】
- **单轴螺旋桨 + 十字艉舵**。【待建模】
- 无消音瓦。【待建模】

## 3. 动力

- 反应堆：**1 × S5W 压水堆**
- 主推进：2 台齿轮传动汽轮机，**15,000 shp（11,000 kW）**
- 轴系：单轴
- 航速：水上 16 kn（30 km/h）／水下 22 kn（41 km/h）
- 续航：无限（受食品限制）

## 4. 武备

### 弹道导弹

- **16 具 Polaris A1 / A3 发射筒**
- Polaris A1 弹长：约 8.7 m；A3 约 9.86 m【待确认】

### 鱼雷

- **6 具 533 mm（21 英寸）鱼雷发射管**
- 载雷量：**12 枚**
- 发射管长度：UNKNOWN【缺失】

## 5. 传感器与电子设备

【缺失】型号清单未取得。典型配置为艇艏声呐 + 潜望镜 + 雷达。

## 6. 潜深与乘员

- 试验深度：**700 ft（210 m）**
- 编制：**两套艇员（蓝/金）轮换，每套 12 名军官 + 100 名士兵**

## 7. 建模要点

1. 全长 116.3 m / 宽 10 m / 吃水 8.8 m。【待建模】
2. **导弹舱隆起段 + 16 具发射筒盖**（本级最核心识别特征）。【待建模】
3. 围壳前移，带可收放艏水平舵。【待建模】
4. 单轴螺旋桨 + 十字艉舵。【待建模】
5. 与 Skipjack 级共用艇体几何（本级是其改装型）。【待确认】
