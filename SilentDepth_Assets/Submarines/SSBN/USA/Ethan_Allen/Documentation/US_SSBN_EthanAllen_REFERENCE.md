# US_SSBN_EthanAllen Ethan Allen（伊桑·艾伦级）

> 资料状态：【已有】资料文档【缺失】模型【待建模】・最后更新：2026-09-11

## 1. 身份与定位

- 国家：美国（United States Navy）
- 艇型：SSBN（核动力弹道导弹潜艇）
- 级：Ethan Allen class
- 前型：George Washington class；后型：Lafayette class
- 定位：美国第二代 SSBN，**第一级从设计之初就作为弹道导弹潜艇建造**（George Washington 级是攻击核潜艇改装而来）
- 同级 5 艘

## 2. 尺度与外形

| 项目 | 数值 |
|---|---|
| 全长 | 410 ft 4 in（125.07 m） |
| 艇体宽 | 33.1 ft（10.1 m） |
| 吃水 | 29 ft 10 in（9.09 m） |
| 排水量（水上） | 6,946 long tons（7,057 t） |
| 排水量（水下） | 7,884 long tons（8,011 t） |

外形特征（面向建模）：

- 比 George Washington 级**加长约 9 m**，导弹舱段与艇体过渡更流畅（本级为原生设计）。【待建模】
- **16 具 Polaris 导弹发射筒盖**在围壳后方沿中线排列。【待建模】
- 围壳带可收放**艏水平舵**。【待建模】
- **单轴螺旋桨 + 十字艉舵**。【待建模】
- 无消音瓦。【待建模】

## 3. 动力

- 反应堆：**1 × S5W 压水堆**
- 主推进：2 台齿轮传动汽轮机，**15,000 shp（11,000 kW）**
- 轴系：单轴
- 航速：水上 16 kn（30 km/h）／水下 22 kn（41 km/h）

## 4. 武备

### 弹道导弹

- **16 具 Polaris A2 / A3 发射筒**
- Polaris A2 弹长：约 9.45 m；A3 约 9.86 m【待确认】

### 鱼雷

- **4 具 533 mm（21 英寸）鱼雷发射管**（比 George Washington 级少 2 具）
- 载雷量：**12 枚**
- 发射管长度：UNKNOWN【缺失】

## 5. 传感器与电子设备

【缺失】型号清单未取得。典型配置为艇艏声呐 + 潜望镜 + 雷达。

## 6. 潜深与乘员

- 试验深度：**1,300 ft（400 m）**
- 编制：**12 名军官 + 128 名士兵**（蓝/金两套艇员轮换）

## 7. 建模要点

1. 全长 125.07 m / 宽 10.1 m / 吃水 9.09 m。【待建模】
2. 与 George Washington 级的差异：**更长、导弹舱过渡更流畅、鱼雷管 6→4**。【待确认】
3. 16 具 Polaris 发射筒盖。【待建模】
4. 围壳舵 + 单轴螺旋桨 + 十字艉舵。【待建模】
