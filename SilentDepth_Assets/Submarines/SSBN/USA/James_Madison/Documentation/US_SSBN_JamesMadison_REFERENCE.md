# US_SSBN_JamesMadison James Madison（詹姆斯·麦迪逊级）

> 资料状态：【已有】资料文档【缺失】模型【待建模】・最后更新：2026-09-11

## 1. 身份与定位

- 国家：美国（United States Navy）
- 艇型：SSBN（核动力弹道导弹潜艇）
- 级：James Madison class
- 前型：Lafayette class；后型：Benjamin Franklin class
- 定位：Lafayette 级的改进型，主要改进为可发射 **Poseidon C3 / Trident I C4** 导弹
- 同级 10 艘

## 2. 尺度与外形

| 项目 | 数值 |
|---|---|
| 全长 | 425 ft（130 m） |
| 艇体宽 | 33 ft（10 m） |
| 吃水 | 28 ft 6 in（8.69 m） |
| 排水量（水上） | 7,325 long tons（7,443 t） |
| 排水量（水下） | 8,251 long tons（8,383 t） |

外形特征（面向建模）：

- **尺寸与 Lafayette 级、Benjamin Franklin 级完全相同**——三级在数据上无法区分。【待确认】
- 围壳位于艇体前段，带可收放艏水平舵。【待建模】
- 围壳后方 16 具导弹发射筒盖。【待建模】
- 单轴螺旋桨 + 十字艉舵。【待建模】
- **本级与 Lafayette 级的可见差别主要在导弹舱段的筒盖与配套结构**（为容纳更长的
  Poseidon / Trident I 导弹，舱段内部与筒盖可能有细微改动），需照片佐证。【待确认】

## 3. 动力

- 反应堆：**1 × S5W 压水堆**
- 主推进：2 台齿轮传动汽轮机，**15,000 shp（11,000 kW）**
- 轴系：单轴
- 航速：水上 16 kn（30 km/h）／水下 21 kn（39 km/h）

## 4. 武备

### 弹道导弹

- **16 具发射筒**
- 可用导弹：**Polaris A3 → Poseidon C3 → Trident I C4**（随年代换装）
- Polaris A3 约 9.86 m；Poseidon C3 约 10.36 m；Trident I C4 约 10.4 m【待确认】

### 鱼雷

- **4 具 533 mm（21 英寸）鱼雷发射管**
- 载雷量：**12 枚**
- 发射管长度：UNKNOWN【缺失】

## 5. 传感器与电子设备

【缺失】型号清单未取得。典型配置为艇艏声呐 + 潜望镜 + 雷达；后期部分艇加装拖曳阵。

## 6. 潜深与乘员

- 试验深度：**1,300 ft（400 m）**
- 编制：**两套艇员（蓝/金），每套 14 名军官 + 126 名士兵**
