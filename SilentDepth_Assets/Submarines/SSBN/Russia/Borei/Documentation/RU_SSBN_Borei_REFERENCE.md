# RU_SSBN_Borei Borei（北风之神级 / Project 955）

> 资料状态：【已有】资料文档【缺失】模型【待建模】・最后更新：2026-09-11

## 1. 身份与定位

- 国家：俄罗斯
- 艇型：SSBN（核动力弹道导弹潜艇）
- 级 / 项目号：Borei class / **Project 955**
- 北约代号：Dolgorukiy class
- 前型：Delta IV class、Typhoon class；后型：Arcturus class
- 建造厂：Sevmash（北德文斯克），设计局 Rubin
- 状态：建造期 1996 至今；服役期 2013 至今；计划 14 艘，已完工并全部在役 8 艘
- 造价：约 **7.13 亿美元 / 艘**

> 本资产对应 **955 基础型**；改进型 955A 另见 `RU_SSBN_BoreiA`。

## 2. 尺度与外形

| 项目 | 数值 |
|---|---|
| 全长 | 170 m（557 ft 9 in） |
| 艇体宽 | 13.5 m（44 ft 3 in） |
| 吃水 | 10 m（32 ft 10 in） |
| 排水量（水上） | 14,720 t |
| 排水量（水下） | 24,000 t |

外形特征（面向建模）：

- **围壳位于艇体前段**，围壳后方为 **16 具 Bulava 导弹发射筒**的隆起段。【待建模】
- **单轴泵喷推进器**。【待建模】
- **十字艉舵 + 水平舵无垂直端板**——**这是与 955A 的关键区别**。【待确认】
- 围壳外形与 955A 不同（955A 改动了围壳几何）。【待确认】
- 艇艏鱼雷发射管开口。【待建模】
- 消音瓦覆盖，分块清晰。【待建模】

## 3. 动力

- 反应堆：**1 × OK-650V 压水堆**
- 主推进：**1 × 汽轮机，50,000 shp**
- 推进器：**1 × 泵喷**
- 航速：水下 **29 kn（54 km/h）**；水上 15 kn
- 续航：无限
