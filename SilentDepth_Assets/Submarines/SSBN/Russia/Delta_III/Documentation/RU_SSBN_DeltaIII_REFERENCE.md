# RU_SSBN_DeltaIII Delta III（德尔塔 III 级 / 667BDR 海鲑）

> 资料状态：【已有】资料文档【缺失】模型【待建模】・最后更新：2026-09-10

## 1. 身份与定位

- 国家：苏联（设计/建造/主要服役期），苏联解体后由俄罗斯继承
- 艇型：SSBN（核动力弹道导弹潜艇）
- 级 / 项目号：**Delta III class / Project 667BDR Kalmar（海鲑）**
- 北约代号：Delta III
- 建造厂：Severodvinsk（北德文斯克，Sevmash）
- 建造期：1974–1982；服役起于 1976 年
- 同级建造：**14 艘**；现役：**1 艘**（资料口径随年份变化）【待确认】
- 前型：Delta II（667BD Murena-M）；后型：Typhoon（941）与 Delta IV（667BDRM）
- 本级是 Delta 家族的中期主力型，也是第一型具备「单次齐射任意数量导弹」能力的苏联 SSBN。
- 现役/退役明细与舰队归属随资料年份不同，逐艇状态需人工核实【待确认】。

## 2. 尺度与外形

| 项目 | 数值 |
|---|---|
| 全长 | 166 m（544 ft 7 in） |
| 艇体宽（Beam） | 12.3 m（40 ft 4 in） |
| 吃水 | 8.8 m（29 ft） |
| 排水量（水上） | 13,500 t |
| 排水量（水下） | 18,200 t |

外形特征（面向建模）：

- **双壳体结构**：外层是薄壁低磁钢外壳，内部是更厚的耐压壳，两层之间可见明显间距与排水开口。【待建模】
- **D-9R 导弹舱龟背**：16 个发射筒全部布置在围壳后方的加长龟背内，龟背轮廓比 Delta I/II 更长、更高，是区分三代 Delta 的第一外观特征。【待建模】
- **围壳位置**：围壳位于艇体前部，其后紧接导弹舱；围壳顶部集中潜望镜与桅杆群。【待建模】
- **艉部构型**：十字舵布局，双轴，每轴一具**五叶固定螺距桨 + 环罩（shrouded propeller）**。【待建模】
- **艏水平舵**：位于艏部（不采用围壳舵）。【待确认】具体前后位置未见权威图纸。
- 「海鲑」级的外形与 Delta II 高度接近，建模时必须以龟背长度与发射筒数量作为主要区分依据，避免把两型做成同一壳体。【待建模】

## 3. 动力

- 反应堆：2 座压水堆（PWR，型号 UNKNOWN）【缺失】
- 主机：2 台蒸汽轮机，总输出 **44,700 kW（59,900 shp）**
- 推进器：双轴，各一具**五叶固定螺距螺旋桨**，带环罩
- 航速：水上 14 kn / 水下 24 kn

## 4. 武备

**弹道导弹**

- 发射系统：**D-9R**，发射筒 **16 具**，全部位于围壳后方导弹舱
- 弹型：**R-29R（SS-N-18 Stingray）**，每枚可携带 3–7 个 MIRV
- 射程：6,500–8,000 km，随再入体数量变化
- 齐射能力：可一次齐射任意数量导弹（本级首创能力）

## 5. 传感器与电子设备

公开来源提到的主要系统（型号以俄方编号为准）：

- 战斗管理系统：**Almaz-BDR**，用于保障深水鱼雷发射【已有】
- 惯性导航：**Tobol-BD → Tobol-M-1 → Tobol-M-2**（Delta II 用 Tobol-BD，本级换装 Tobol-M 系列）
- 水声导航系统：**Bumblebee**（借助水声浮标测定自身位置）
- 水声系统：**Rubikon**（替代 667BD 上的 Kerch 系统）
