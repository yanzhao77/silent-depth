# RU_SSBN_Hotel Hotel（旅馆级 / Project 658）

> 资料状态：【已有】资料文档【缺失】模型【待建模】・最后更新：2026-09-11

## 1. 身份与定位

- 国家：苏联
- 艇型：SSBN（核动力弹道导弹潜艇）
- 级 / 项目号：Hotel class / **Project 658、658M**
- 北约代号：Hotel
- 定位：**苏联第一代弹道导弹核潜艇**，由 November 级（Project 627）放大发展而来
- 后续：本级部分艇改装为 Project 701（攻击型）

## 2. 尺度与外形

| 项目 | 数值 |
|---|---|
| 全长 | 114 m（374 ft） |
| 艇体宽 | 9.2 m（30 ft 2 in） |
| 吃水 | 7.31 m（24 ft） |
| 排水量（水下，658M） | 5,500 long tons（5,588 t）【待确认】（维基标注 citation needed） |

外形特征（面向建模）：

- **围壳位于艇体中部，围壳内部/后方容纳导弹发射筒**——这是 Hotel 级最独特的外形：导弹筒**穿透并高出围壳**，而不是像美制 SSBN 那样平躺在艇体背部。【待建模】
- **3 具导弹发射筒**呈品字形或单列布置，筒口在围壳内。【待建模】
- 艇体为**雪茄形**（继承 November 级）。【待建模】
- **双轴螺旋桨 + 十字艉舵**。【待建模】
- 无消音瓦。【待建模】

## 3. 动力
