# RU_SSBN_DeltaIV Delta IV（德尔塔 IV 级 / 667BDRM 海豚）

> 资料状态：【已有】资料文档【缺失】模型【待建模】・最后更新：2026-09-10

## 1. 身份与定位

- 国家：苏联（建造）→ 俄罗斯联邦（继续服役）
- 艇型：SSBN（核动力弹道导弹潜艇）
- 级 / 项目号：**Delta IV class / Project 667BDRM Delfin（海豚）**
- 北约代号：Delta IV
- 建造厂：Severodvinsk（北德文斯克，Sevmash），1981–1992 年建造
- 同级建造：**7 艘**；现役：**6 艘**（资料口径随年份变化）【待确认】
- 前型：Delta III（667BDR）与 Typhoon（941）；后型：Borei（955）
- 服役起于 1984 年，最后一艘为 **K-407 Novomoskovsk**；母港 Sayda Guba，隶属北方舰队
- 本级是俄罗斯海基战略核力量在 Borei 形成战斗力之前的核心，属于「现役主力级」。

外形特征（面向建模）：

- **加长导弹舱龟背**：16 具发射筒，龟背自围壳后方延伸至艇体后段，前段与围壳几乎连成一体。【待建模】
- **围壳**：位于艇体前部，外形与 Delta III 接近，顶部为桅杆/潜望镜/天线群。【待建模】
- **艏部**：圆钝艏型，艏水平舵位于艏部；艏部有 4 具 533 mm 鱼雷发射管开口（水中发射时可见）。【待建模】
- **艉部**：双轴，各一具**固定螺距桨 + 环罩（shrouded propeller）**，十字舵。【待建模】
- **导弹舱盖形状差异**：最后 4 个发射筒盖与前 12 个形状不同，实艇照片（Tula K-114 全开盖航行）可直接看到。【已有】参考图
- 表面消声瓦覆盖完整，外观可见砖块状分缝。【待确认】
- 「Delta IV Stretch」为改装后的特殊任务构型，与本级作战艇外形不同，建模时不要混用。【不许推断】改装艇内部细节
