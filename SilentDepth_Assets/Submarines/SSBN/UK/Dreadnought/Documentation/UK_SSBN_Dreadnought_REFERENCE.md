# UK_SSBN_Dreadnought Dreadnought（无畏级 / 英国新一代 SSBN）

> 资料状态：【已有】资料文档【缺失】模型【待建模】・最后更新：2026-09-11

## 1. 身份与定位

- 国家：英国（Royal Navy）
- 艇型：SSBN（核动力弹道导弹潜艇）
- 级：Dreadnought class（新一代战略核潜艇）
- 前型：Vanguard class
- 建造厂：BAE Systems Submarines，Barrow-in-Furness
- 计划数量：**4 艘**，全部在建（Active 0）
- 首艇预计：**2030 年代初**交付
- 成本：项目全寿命约 **310 亿英镑**（2016 年价），单艇约 **77.5 亿英镑**

> **重要区分**：本级与资产库中 T2/T3 档的 `UK_SSN_Dreadnought` **不是同一型**。
> 前者是 1960 年代英国第一艘核潜艇 HMS Dreadnought（S101），本级是 21 世纪的新一代弹道导弹潜艇。两者仅有舰名继承关系，**建模时绝不可混用**。

【已有】资料文档；【缺失】模型。
