# CN_SSN_Type093B Type 093B（093B 型）

> 资料状态：【已有】资料文档【缺失】模型【待建模】・最后更新：2026-09-11

## 1. 身份与定位

- 国家：中国（中国人民解放军海军潜艇部队）
- 艇型：SSN（核动力攻击潜艇）
- 型号：Type 093B（093 系列的后期改进批次）
- 北约代号：仍归入 **Shang class（商级）**
- 前型：Type 093 / 093A；后型：Type 095
- 定位：**中国首型采用泵喷推进器的攻击核潜艇**（公开资料支持）

## 2. 尺度与外形

| 项目 | Type 093B |
|---|---|
| 全长 | 110 m（360 ft 11 in） |
| 艇体宽 | 11 m（36 ft 1 in） |
| 吃水 | 7.5 m（24 ft 7 in） |
| 排水量（水下） | 6,700–7,000 t |
| 航速 | 30 kn（56 km/h） |

外形特征（面向建模）：

- **泵喷推进器（pump-jet）**——本级与 093 / 093A 最明确的可见差异。【待建模】
- **长度比 093/093A 增加约 1.5 m**（110 m vs 108.5 m）。【待建模】
- 围壳外形可能进一步优化，**导弹垂直发射装置的有无与位置需核实**
  （公开分析普遍认为本级具备垂发巡航导弹能力，但外观表现未确认）。【待确认】
- 艇艏 **6 具 533 mm 发射管**。【待确认】
- 消音瓦覆盖，分块较明显。【待确认】

## 3. 动力

- 反应堆：**2 座 70–75 MW 压水堆**
- 推进器：**1 × 泵喷（pump-jet）**
- 航速：30 kn（56 km/h）
- 续航：无限

## 4. 武备

- **6 具 533 mm（21 in）鱼雷发射管**
- 可用武器：**Yu-3 / Yu-4 / Yu-6 鱼雷**、**YJ-18 反舰巡航导弹**、**YJ-82 反舰巡航导弹**
- 【待确认】垂直发射巡航导弹舱（若存在，需建模筒盖）
- 载弹量：UNKNOWN【缺失】
- 发射管长度：UNKNOWN【缺失】

【缺失】全部 UNKNOWN。本级为较新批次，声呐与作战系统应有升级，但型号未公开。

## 6. 潜深与乘员

## 7. 建模要点

1. 全长 110 m / 宽 11 m / 吃水 7.5 m。【待建模】
2. **泵喷推进器**——本级最重要的识别特征。【待建模】
3. 【待确认】垂直发射装置是否存在及其筒盖位置（若存在，是 093B 的另一识别点）。
4. 艇艏 6 具 533 mm 发射管。【待确认】
5. **与 093 / 093A 的差异**：本级更长、泵喷，是三者中最值得独立建模的一艘。
