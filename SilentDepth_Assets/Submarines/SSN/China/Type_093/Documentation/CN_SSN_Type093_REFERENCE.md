# CN_SSN_Type093 Type 093（093 型 / 北约代号 Shang 商级）

> 资料状态：【已有】资料文档【缺失】模型【待建模】・最后更新：2026-09-11

## 1. 身份与定位

- 国家：中国（中国人民解放军海军潜艇部队）
- 艇型：SSN（核动力攻击潜艇）
- 型号：Type 093，中国代号 **09-III**；北约代号 **Shang class（商级）**
- 前型：Type 091；后型：Type 095
- 定位：中国第二代核动力攻击潜艇
- **本资产对应基础型 Type 093 / 093A**；Type 093B 另见 `CN_SSN_Type093B`

## 2. 尺度与外形

| 项目 | Type 093 / 093A | Type 093B |
|---|---|---|
| 全长 | 108.5 m（356 ft） | 110 m（360 ft 11 in） |
| 排水量（水下） | 6,675 t | 6,700–7,000 t |
| 航速 | 28 kn（093）/ 30 kn（093A） | 30 kn（56 km/h） |

| 项目 | 数值 |
|---|---|
| 艇体宽 | 11 m（36 ft 1 in） |
| 吃水 | 7.5 m（24 ft 7 in） |
| 编制 | 100 人 |

外形特征（面向建模）：

- **围壳位于艇体前段**，外形较 091 更流线。【待建模】
- **推进器：093 为基础型螺旋桨；093B 采用泵喷推进器**——本级与 093B 的重要外形分界。【待确认】
- 艇体为水滴形，艏部圆钝。【待建模】
- 艇艏 **6 具 533 mm 发射管**。【待建模】
- 消音瓦覆盖情况未确认。【待确认】

## 3. 动力

- 反应堆：**2 座 70–75 MW 压水堆**
- 推进器：**1 × 泵喷（Type 093B）**；基础型为螺旋桨【待确认】
- 航速：28–30 kn（52–56 km/h）
- 续航：无限

【缺失】汽轮机功率、单轴/双轴、螺旋桨叶数。
