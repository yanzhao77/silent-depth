# CN_SSN_Type093A Type 093A（093A 型）

> 资料状态：【已有】资料文档【缺失】模型【待建模】・最后更新：2026-09-11

## 1. 身份与定位

- 国家：中国（中国人民解放军海军潜艇部队）
- 艇型：SSN（核动力攻击潜艇）
- 型号：Type 093A（093 的改进批次）
- 北约代号：仍归入 **Shang class（商级）**
- 前型：Type 093；后型：Type 093B → Type 095

> **本项目的三个 093 资产**：`CN_SSN_Type093`（T7）、`CN_SSN_Type093A`（T8）、
> `CN_SSN_Type093B`（T9）。公开资料把三型写在同一页，**只有 093B 有明确的可见差异
> （泵喷推进器）**；093 与 093A 的差异在公开资料中并不充分。

## 2. 尺度与外形

| 项目 | Type 093 / 093A |
|---|---|
| 全长 | 108.5 m（356 ft） |
| 艇体宽 | 11 m（36 ft 1 in） |
| 吃水 | 7.5 m（24 ft 7 in） |
| 排水量（水下） | 6,675 t |
| 航速 | 30 kn（56 km/h，093A） |

外形特征（面向建模）：

- **与 Type 093 尺寸完全相同**，可见差异缺乏公开资料支持。【缺失】
- 推进器：**093A 为螺旋桨**（093B 才是泵喷）。【待确认】
- 围壳位于艇体前段，外形较 091 更流线。【待建模】
- 艇艏 **6 具 533 mm 发射管**。【待建模】
- 消音瓦情况未确认。【待确认】

## 3. 动力

- 反应堆：**2 座 70–75 MW 压水堆**
- 航速：30 kn（56 km/h）
- 续航：无限

【缺失】汽轮机功率、轴数、螺旋桨叶数。

## 4. 武备

- **6 具 533 mm 鱼雷发射管**
- 可用武器：**Yu-3 / Yu-4 / Yu-6 鱼雷**、**YJ-18 反舰巡航导弹**、**YJ-82 反舰巡航导弹**
- 载弹量：UNKNOWN【缺失】
- 发射管长度：UNKNOWN【缺失】

## 5. 传感器与电子设备

【缺失】全部 UNKNOWN。093A 相比 093 据称升级了声呐与作战系统，但无公开型号。

## 6. 潜深与乘员

- 编制：约 100 人（沿用 093 数据）【待确认】
- 试验深度：UNKNOWN【缺失】

## 7. 建模要点

1. 全长 108.5 m / 宽 11 m / 吃水 7.5 m。【待建模】
2. **与 Type 093 的差异需先确认**；若无法确认，建议与 093 共用几何。【待确认】
3. **与 Type 093B 的差异**：093B 为泵喷、长 110 m——本级应为螺旋桨。【待确认】
4. 艇艏 6 具 533 mm 发射管。【待建模】
