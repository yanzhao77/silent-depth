# FR_SSN_Rubis Rubis（红宝石级 / 法国第一代攻击核潜艇）

> 资料状态：【已有】资料文档【缺失】模型【待建模】・最后更新：2026-09-11

## 1. 身份与定位

- 国家：法国（Marine nationale）
- 艇型：SSN（核动力攻击潜艇）
- 级：Rubis class（亦称 SNA 72 型）
- 前型：无（法国第一代攻击核潜艇）；后型：Suffren class
- 定位：**世界上吨位最小的核动力攻击潜艇之一**，共 6 艘

## 2. 尺度与外形

| 项目 | 数值 |
|---|---|
| 全长 | 73.6 m（241 ft 6 in） |
| 艇体宽 | 7.6 m（24 ft 11 in） |
| 吃水 | 6.4 m（21 ft 0 in） |
| 排水量（水上） | 2,400 t |
| 排水量（水下） | 2,600 t |

外形特征（面向建模）：

- **显著小于同期美苏英核潜艇**（全长仅 73.6 m），这是本级最鲜明的特点。【待建模】
- **围壳非常靠前**，且外形紧凑。【待建模】
- **单轴螺旋桨 + 十字艉舵**，艉舵上另有小型结构。【待确认】
- 艇艏 **4 具 533 mm 发射管**。【待建模】
- 【待确认】消音瓦情况。

## 3. 动力

- 反应堆：**CAS-48 压水堆，48 MW**（低浓缩铀 LEU 7%）
- 主推进：2 台推进汽轮发电机（2 × 3,150 kW）+ **1 台主电机（8,448 shp）**
- 轴系：单轴
- 辅机：1 台 SEMT Pielstick 8PA4V185SM 柴油发电机（450 kW）
- 航速：**25 kn（46 km/h）**
- 续航：无限距离，**堆芯寿命 20–25 年**
- 自持力：**45 天**

## 4. 武备

- **4 具 533 mm（21 in）鱼雷发射管**
- 载弹量：**14 件混装**
- 可用武器：
  - **F17 mod2 鱼雷**
  - **F21 Artemis 鱼雷**（*Perle* 号改装后具备）
  - **Exocet SM39 反舰导弹**
  - 水雷
- 发射管长度：UNKNOWN【缺失】
- F17 弹长约 5.4 m；F21 约 6.0 m；SM39 约 4.7 m（含运载舱）【待确认】

## 5. 传感器与电子设备

## 6. 潜深与乘员

- 试验深度：**超过 300 m（980 ft）**
- 编制：**10 名军官 + 52 名海军准尉 + 8 名士官与水兵**（约 70 人）

## 7. 建模要点

1. 全长 73.6 m / 宽 7.6 m / 吃水 6.4 m——**本项目的核潜艇中最小的一艘**。【待建模】
2. 紧凑且靠前的围壳外形（法国流派）。【待建模】
3. 单轴螺旋桨 + 十字艉舵。【待建模】
4. 艇艏 4 具 533 mm 发射管。【待建模】
