# UK_SSN_Trafalgar Trafalgar（特拉法尔加级）

> 资料状态：【已有】资料文档【缺失】模型【待建模】・最后更新：2026-09-11

## 1. 身份与定位

- 国家：英国（Royal Navy）
- 艇型：SSN（核动力攻击潜艇）
- 级：Trafalgar class
- 前型：Swiftsure class；后型：Astute class
- 定位：英国冷战后期的攻击核潜艇主力，共 7 艘，2010 年代逐步退役

## 2. 尺度与外形

| 项目 | 数值 |
|---|---|
| 全长 | 85.4 m（280 ft 2 in） |
| 艇体宽 | 9.8 m（32 ft 2 in） |
| 吃水 | 9.5 m（31 ft 2 in） |
| 排水量（水上） | 4,500–4,800 t |
| 排水量（水下） | 5,200–5,300 t |

外形特征（面向建模）：

- **与 Swiftsure 级外形非常接近**，主要差别在艏部细部与内部，**建模时需以照片区分**。【待确认】
- **采用泵喷推进器（pump jet propulsor）**——这是与 Swiftsure 级螺旋桨最本质的区别。【待建模】
- 围壳位于艇体前段，围壳舵。【待建模】
- **1 具可收放辅助螺旋桨**（auxiliary retractable prop），用于应急/低速。【待建模】
- 艇艏 **5 具 533 mm 发射管**（与 Swiftsure 级相同数量）。【待建模】
- 消音瓦覆盖，表面可见分块。【待建模】

## 3. 动力

- 反应堆：**1 × Rolls-Royce PWR1**
- 主推进：**2 × GEC 汽轮机 → 泵喷推进器**
- 发电：2 × WH Allen 汽轮发电机（3.2 MW）+ 2 × Paxman 柴油发电机（2,800 shp / 2.1 MW）
- 应急：1 台应急驱动电机 + 1 具可收放辅助螺旋桨
- 航速：水下**超过 30 kn（56 km/h）**
- 续航：无限

## 4. 武备

- **5 具 533 mm（21 英寸）鱼雷发射管**
- 载弹量：**最多 30 件武器**
- 可用武器：**Tomahawk Block IV 巡航导弹**、**Spearfish 重型鱼雷**
- 发射管长度：UNKNOWN【缺失】
- Tomahawk 弹长约 6.25 m；Spearfish 约 7.0 m【待确认】
