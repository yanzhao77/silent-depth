# UK_SSN_Valiant Valiant（勇士级）

> 资料状态：【已有】资料文档【缺失】模型【待建模】・最后更新：2026-09-11

## 1. 身份与定位

- 国家：英国（Royal Navy）
- 艇型：SSN（核动力攻击潜艇）
- 级：Valiant class
- 前型：HMS Dreadnought (S101)；后型：Churchill class → Swiftsure class
- 定位：**英国自主设计的第一代攻击核潜艇**（Dreadnought 用的是美国反应堆，本级改用英国自研堆）
- 同級 2 艘：HMS Valiant (S102)、HMS Warspite (S103)

## 2. 尺度与外形

| 项目 | 数值 |
|---|---|
| 全长 | 285 ft（87 m） |
| 艇体宽 | 33 ft 3 in（10.13 m） |
| 吃水 | 27 ft（8.2 m） |
| 排水量（水上） | 4,400 long tons（4,500 t） |
| 排水量（水下） | 4,900 long tons（5,000 t） |

外形特征（面向建模）：

- 艇体比后续的 Swiftsure 级**更短且更"胖"**（Swiftsure 比本级短 4 m 但线型更饱满）。【待建模】
- 围壳位于艇体前段，**围壳舵**。【待建模】
- **单轴螺旋桨 + 十字艉舵**。【待建模】
- **艏水平舵位置比 Swiftsure 级更靠后**——这是区分两级的要点。【待确认】
- 艇艏 **6 具**发射管（Swiftsure 减为 5 具）。【待建模】
- 无消音瓦（本级早于英国消音瓦普及）。【待确认】

## 3. 动力

- 反应堆：**1 × Rolls-Royce 压水堆**（英国自研）
- 主推进：**2 台汽轮机 → 1 根轴**
- 航速：水上 20 kn（37 km/h）／水下 **29 kn**（54 km/h）
- 续航：无限（受食品限制）

## 4. 武备

| 时期 | 配置 |
|---|---|
| 早期 | **6 具 533 mm 艇艏发射管**；32 枚 Mk VIII / Tigerfish 鱼雷；**或** 64 枚 Mk 5 / Mk 6 水雷 |
| 后期 | 26 枚鱼雷 + **6 枚 UGM-84B Harpoon 反舰导弹**；或 Stonefish / Sea Urchin 水雷 |

- 发射管长度：UNKNOWN【缺失】
