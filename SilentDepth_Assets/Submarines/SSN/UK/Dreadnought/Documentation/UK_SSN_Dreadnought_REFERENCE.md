# UK_SSN_Dreadnought Dreadnought（无畏号 S101 / 英国第一艘核潜艇）

> 资料状态：【已有】资料文档【缺失】模型【待建模】・最后更新：2026-09-11

> **名称冲突提醒**：本资产是 1960 年代的 **HMS Dreadnought (S101)**，
> 与 T10 档的 `UK_SSBN_Dreadnought`（英国新一代弹道导弹潜艇）**不是同一型**。
> 本文件只描述 S101。

## 1. 身份与定位

- 国家：英国（Royal Navy）
- 艇型：SSN（核动力攻击潜艇）
- 艇名 / 舷号：**HMS Dreadnought (S101)**
- 定位：**英国第一艘核潜艇**；采用美国 S5W 反应堆，英国自造船体与武器系统
- 同级仅 1 艘（本级即为单艇）

## 2. 尺度与外形

| 项目 | 数值 |
|---|---|
| 全长 | 265.7 ft（81.0 m） |
| 艇体宽 | 31.2 ft（9.5 m） |
| 吃水 | 25.9 ft（7.9 m） |
| 排水量（水上） | 3,500 tons（3,556 t） |
| 排水量（水下） | 4,000 tons（4,064 t） |

外形特征（面向建模）：

- 艇体为**英国式水滴形**，但艏部比美制 Skipjack 略钝。【待建模】
- 围壳位于艇体前段，**围壳上装有艏水平舵**（英国惯例）。【待建模】
- **单轴螺旋桨 + 十字艉舵**。【待建模】
- 无消音瓦。【待建模】
- 艇艏 6 具发射管开口。【待建模】

## 3. 动力

- 反应堆：**1 × Westinghouse S5W**（美国供应）
- 主推进：2 台齿轮传动汽轮机，**15,000 shp（11,000 kW）**
- 轴系：单轴
- 航速：水上 20 kn（37 km/h）／水下 28 kn（52 km/h）

## 4. 武备

- **6 具 533 mm（21 英寸）艇艏鱼雷发射管**
- 载雷量：**24 枚**
- 可用弹种：英国 Mk VIII 直航鱼雷等（本级服役早期）【待确认】
- 发射管长度：UNKNOWN【缺失】
