# US_SSN_Sturgeon Sturgeon（鲟鱼级）

> 资料状态：【已有】资料文档【缺失】模型【待建模】・最后更新：2026-09-11

## 1. 身份与定位

- 国家：美国（United States Navy）
- 艇型：SSN（核动力攻击潜艇）
- 级：Sturgeon class
- 前型：Thresher/Permit class；后型：Los Angeles class
- 定位：冷战时期美国**建造数量最多的攻击核潜艇**（37 艘），
  也是第一批可发射 SUBROC、Harpoon、Tomahawk 的多用途艇

## 2. 尺度与外形

| 项目 | 数值 |
|---|---|
| 全长（短艇体） | 292 ft 3 in（89.08 m） |
| 全长（长艇体） | 302 ft 3 in（92.13 m） |
| 全长（Glenard P. Lipscomb，试验型） | 365 ft（111.25 m） |
| 全长（Parche 改装后） | 401 ft（122.22 m） |
| 艇体宽 | 31 ft 8 in（9.65 m） |
| 吃水 | 24 ft 5 in（7.44 m） |
| 排水量（水上） | 3,640 long tons（3,698 t） |
| 排水量（水下） | 4,640 long tons（4,714 t） |

外形特征（面向建模）：

- 水滴形艇体，**围壳靠前**，围壳带可收放艏水平舵。【待建模】
- **鱼雷发射管位于艇体中部（amidships）并呈斜向布置**——不是艇艏正前方，这是本级最重要的外形特征。【待建模】
- 单轴螺旋桨 + 十字艉舵。【待建模】
- 【待确认】本级后期艇加装了消音瓦。
- 短艇体与长艇体两种规格，长度差约 3 m，建模前需确认采用哪一种。【待确认】

## 3. 动力

- 反应堆：**1 × S5W 压水堆**
- 主推进：2 台汽轮机，合计 **15,000 shp（11,000 kW）**
- 轴系：单轴
- 航速：水上 15 kn（28 km/h）／水下 26 kn（48 km/h）
- 续航：无限（受食品限制）

## 4. 武备

- **4 具 533 mm（21 英寸）艇体中部斜置发射管**
- 载弹量：最多 **21 枚再装填武器**，典型混装：
  - Mk 48 / Mk 48 ADCAP 重型鱼雷
  - 通常 4 枚 Harpoon 反舰导弹，或最多 **8 枚 Tomahawk 巡航导弹**
  - 2–4 枚 SUBROC 反潜导弹
- 布雷配置：**Mk 67 SLMM（潜艇布放机动水雷）与 Mk 60 CAPTOR 水雷**替代鱼雷
- 发射管长度：UNKNOWN【缺失】
- Tomahawk 弹长：约 6.25 m（含助推器）；Harpoon（UGM-84）约 6.4 m（含运载舱）【待确认】

## 6. 潜深与乘员

- 编制：**107 人**

## 7. 建模要点

1. 全长按短艇体 89.08 m 或长艇体 92.13 m（**先确认采用哪一种**）。【待确认】
2. **艇体中部斜置的 4 具发射管**——本级最具辨识度的特征，不能按艇艏正置建模。【待建模】
3. 围壳 + 可收放艏水平舵。【待建模】
4. 单轴螺旋桨 + 十字艉舵。【待建模】
5. 消音瓦覆盖范围（后期改装）。【待确认】
