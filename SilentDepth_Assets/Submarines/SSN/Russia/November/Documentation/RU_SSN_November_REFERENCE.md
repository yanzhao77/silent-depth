# RU_SSN_November November（十一月级 / Project 627）

> 资料状态：【已有】资料文档【缺失】模型【待建模】・最后更新：2026-09-11

## 1. 身份与定位

- 国家：苏联
- 艇型：SSN（核动力攻击潜艇）
- 级 / 项目号：November class / **Project 627、627A、645**
- 北约代号：November
- 定位：**苏联第一代核动力潜艇**，也是苏联第一型批量建造的核潜艇

## 2. 尺度与外形

|---|---|---|---|
| 全长 | — | 107.4 m | 109.8 m |

外形特征（面向建模）：

- **雪茄形艇体**（不是水滴形），艏艉都较细长——与同期美制 Skipjack 的水滴形形成鲜明对比。【待建模】
- **围壳位于艇体中部偏前**，较高且体积大。【待建模】
- **双轴螺旋桨 + 十字艉舵**。【待建模】
- 艇艏有 8 具发射管开口，排布密集。【待建模】
- 表面无消音瓦。【待建模】
- 【待确认】Project 645 因使用液态金属冷却堆，外形可能与 627/627A 有局部差异。

## 3. 动力

- 反应堆：**2 × VM-A 水冷压水堆，各 70 MW**
- 主推进：2 台 60-D 汽轮机组，总 **35,000 hp**
- 轴系：**双轴**
- 辅机：2 台 GPM-21 汽轮发电机（各 1,400 kW）、2 台 DG-400 柴油机（各 460 hp）、2 台 PG-116 辅助电机（各 450 hp）
- Project 645 改用 **2 × VT-1 液态金属冷却堆，各 73 MW**
- 航速：水上 15.2 / 15.5 / 14.7 kn；水下 30 / 28 / 30.2 kn（627 / 627A / 645）
- 自持力：**50–60 天**

## 4. 武备

- **8 具 533 mm 艇艏鱼雷发射管**
- 载雷量：**20 枚**（SET-65 或 53-65K）
- 发射管长度：UNKNOWN【缺失】
- 【缺失】是否具备水雷布放与导弹发射能力未取得资料

【缺失】型号清单未取得。本级为 1950 年代末产品，典型配置为艇艏声呐 + 潜望镜 + 雷达。
