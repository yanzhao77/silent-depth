# RU_SSN_YasenM Yasen-M（亚森-M / Project 885M）

> 资料状态：【已有】资料文档【缺失】模型【待建模】・最后更新：2026-09-11

## 1. 身份与定位

- 国家：俄罗斯
- 艇型：SSN（核动力攻击潜艇）
- 级 / 项目号：Yasen-M class / **Project 885M（Ясень-М）**
- 北约代号：Severodvinsk 级（Yasen 为名称通称）
- 前型：Oscar class、Akula class；后续：Laika class
- 建造厂：Sevmash（北德文斯克）
- 建造期：1993 至今；服役期：2013 至今
- 计划数量：**12 艘**；已完工 7 艘（在役 5 艘，1 艘海试，1 艘已下水舾装）（截至资料日期）
- 单艇造价：Kazan 号 2011 年约 **470 亿卢布**

【已有】本级为俄罗斯现役最新一代攻击核潜艇，公开资料与照片较多。
【缺失】本级没有模型——注意 `Submarines/SSN/Russia/Yasen/` 下现有模型是 **Project 885（非 885M）**，两者不能混用。

## 2. 尺度与外形

| 项目 | Yasen（885） | Yasen-M（885M） |
|---|---|---|
| 全长 | 139.2 m | **130 m** |
| 艇体宽 | 13 m | 13 m |
| 排水量（水上） | 8,600 t | 8,600 t（同级数据） |
| 排水量（水下） | 13,800 t | 13,800 t（同级数据） |

外形特征（面向建模）：

- **885M 比 885 短约 9 m**，缩短来自艇体分段的重排而非简单截短——建模必须按各自长度。【待建模】
- 围壳为低矮流线型，顶部桅杆可全部收放。【待建模】
- 艉部为**单轴泵喷推进器（pump-jet）**，无外露螺旋桨。【待建模】
- 艇体表面敷设消音瓦，分段线清晰可见。【待建模】
- **885M 的艉部与舵面构型与 885 有差异**，需按各自照片核对。【待确认】
- 艇艏上方可见鱼雷发射管开口与舷侧阵声呐窗口。【待建模】

## 7. 建模要点

1. **务必区分 885 与 885M**：本资产为 885M，全长 130 m（现有 Yasen 模型是 885，139.2 m）。【待确认】
2. 单轴**泵喷推进器**——艉部没有外露螺旋桨，这是与 Akula 等上一代最直观的区别。【待建模】
3. 低矮流线围壳 + 可收放桅杆群。【待建模】
4. 圆钝艏部与连续收束的艉部（本级采用球形艏声呐罩）。【待建模】
5. 艇体消音瓦分块与表面开口布局。【待建模】
