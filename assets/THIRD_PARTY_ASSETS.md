# THIRD_PARTY_ASSETS.md — Third-Party Asset Declaration

Project: SILENT DEPTH 《深海猎手》 · Owner: Asset Engineer (t-011)
Requirement: FR-21 §3 (provenance + license gate) · Status: CURRENT (34 assets)

## Declaration

> **ALL assets in SILENT DEPTH are procedurally generated by the asset factory
> (`src/rendering/sprites.ts`) and rendered at runtime with the Canvas 2D API.**
>
> **ZERO third-party assets. ZERO downloaded images. ZERO samples, sprites,
> textures, fonts, sounds or audio samples acquired from any external source.**
>
> **ZERO assets with unknown or unverified copyright.** The license gate
> (docs/ASSET_PIPELINE.md §3) blocks any unverified source before it can be
> registered; `Unknown / Copyright → BLOCK` is enforced for every entry.

## Why there are no third-party assets

- **ADR-003 (procedural assets)**: all sprites/effects are Canvas-drawn in
  code; all audio is WebAudio-synthesized (see docs/AUDIO_DESIGN.md). This is a
  deliberate architectural choice that makes licensing risk zero by
  construction (GAME_ARCHITECTURE.md §1).
- **NFR-2 (fully offline)**: zero runtime network, zero CDN, zero external
  fetches. Assets are code, not files fetched from the internet.
- **FR-21 §3**: the asset factory pipeline's license gate auto-approves CC0 and
  blocks everything unverifiable. Every registry entry must carry
  `license=CC0`, `source=procedural`, `author=DeepSeek Software Factory` —
  enforced by `tests/unit/assets.test.ts`.

## How to verify this declaration

1. `assets/registry.json` — every entry must show `source=procedural`,
   `license=CC0`, and a real sha256.
2. `tests/unit/assets.test.ts` — enforces: exact FR-21 field set, 64-char hex
   sha256 equal to the on-disk hash of `sprites.ts`, local-relative paths only
   (no external URLs), ship-class coverage from `config/balance.json`,
   resolution ≤ 512×512, license gate (CC0 + procedural + correct licenseUrl).
3. `npm test` must be green; `npx tsc --noEmit` must show no new errors from
   `src/rendering/sprites.ts` / `tests/unit/assets.test.ts`.

## If this declaration must ever change

If a future asset is acquired from a third party, the pipeline
(docs/ASSET_PIPELINE.md §7) requires: license gate review (CC0/CC BY/CC BY-SA
approved; CC BY-NC warn/block-commercial; Unknown/Copyright blocked),
attribution recorded in the registry, sha256 of the actual file, and this
document updated to truthfully list the third-party asset and its license —
**before** it may be integrated. Until then, this declaration stands: zero
third-party assets.
